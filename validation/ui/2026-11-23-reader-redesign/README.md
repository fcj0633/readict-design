# 阅读器 UI/UX 优化记录（2026-11-23）

## 结论

正式应用 `/reader/:bookId` 的阅读页 UI 已按 Quiet Reading / Editorial 方向完成本轮优化，并在 Edge headless 下通过 1920×1080、1440×900、1366×768 的实际截图检查。

本轮**只做前端视觉与展示层改造**：没有修改 EPUB 引擎、CFI、进度 API、数据库或阅读偏好契约。M05 查词与 M06 收藏尚未实现，因此词典卡片是明确的**视觉预览**，收藏入口仍不可用；本记录不构成 M04/M05/M06 整体验收。

## 主要改动

### 阅读空间

- 纸面从“正文 canvas 直接铺在页面上”改为独立书页容器：`width: clamp(920px, 76vw, 1100px)`，实测 1920/1440/1366 下分别为 1100/1094/1038px。
- 正文仍保持 660/720px 行宽（设置值不变），纸面通过更大的内边距获得书页感；1920 下正文不再显得单薄。
- 顶部栏降为 60px：只保留 `← 书架`、书名、当前章节；目录和设置从顶部移除。
- 上一页/下一页、页码、全书进度、保存状态移入纸面底部，成为阅读空间的一部分。
- 工具栏改为纸面右侧的 Lucide 圆形图标（目录 / 收藏 / 设置），低对比度、Hover 提示；面板打开时淡出。
- 暖纸主题下纸面与 iframe 背景统一为 `#FFFDF9`，修复了此前正文区域呈米黄色块、与纸面不一致的问题。

### 目录与设置

- 目录默认收起，点击后从右侧打开 340px 抽屉；遮罩、X、Esc 均可关闭。
- 当前章节使用浅绿底、左侧绿条和 Check 标记；打开时自动滚到当前项。
- 目录支持显示层级：M03 manifest 的 TOC 是扁平的，前端按 `PART/BOOK/VOLUME/SECTION/ACT` 标签做**展示层分组**，不修改后端数据或重新导入。
- 设置面板改为分段按钮 + 主题色块：字体、字号、行间距、正文宽度、背景；沿用 `PreferenceSaver` 的自动保存、串行、冲突处理。
- 打开任一面板不改变 iframe 尺寸；实测打开目录前后 iframe 宽高一致。

### 保存状态

- 移除顶部大面积“阅读位置尚未同步”红条。
- 普通保存状态放到纸面底栏：`保存中… / 已保存 / 未同步 · 重试`。
- 未同步使用低饱和暖色小胶囊，并保留重试；持续失败仍清楚可见。
- 冲突保留两选一（用服务器位置 / 保留此处），以纸面内小卡片呈现。
- 修复 `PUT /progress` 响应解析错误：服务端返回直接进度对象，前端误按 `{progress:...}` 解析，导致成功保存被报为“服务响应无法识别”；现在拆分为 `decodeProgressValue` 与 `decodeProgress`，正常保存和重试均显示“已保存”。

### 字体与主题

- iframe 内 `text-align:left`、禁 justify、段落间距 1em、标题层级 1.5em/600、英文断词辅助。
- 三种主题的纸面/画布/文字/分隔线/强调色统一；深色主题保留低对比度纸面与浅绿强调。
- 正文默认 Georgia 20px / 1.8；设置仍只允许既有的 660/720 宽度与 18/20/22/24 字号。

### 查词卡片（视觉预览，非 M05）

- 正式阅读器尚未实现 M05，不能提供真实单词点击、词典查询或收藏。
- 新增仅开发环境可用的 `?preview=dictionary` 视觉入口：在 iframe 中只读定位示例词 `children`，绘制选词高亮，并按视口边缘翻转/夹取卡片位置；不修改 EPUB DOM、CFI 或进度。
- 卡片包含词头、音标、发音按钮、三条释义、原文语境、主动翻译（示例）与收藏占位；卡片顶部明确标注“视觉预览 · M05 未接入”，收藏按钮标注 M06。
- 生产构建不展示该预览；真实 M05 接入时复用 `preview/position.ts` 的定位逻辑和卡片样式。
