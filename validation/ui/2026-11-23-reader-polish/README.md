# 阅读器第二轮 UI 调整记录（2026-11-23）

## 结论

针对上一轮截图暴露的四个问题，正式阅读页已完成第二轮视觉调整，并在 1920×1080、1440×900、1366×768 下用 Edge headless 实际截图验收。上一轮记录与截图保留在 `validation/ui/2026-11-23-reader-redesign/`，本记录是新基线，不覆盖旧证据。

本轮仍未接入 M05 查词与 M06 收藏；词典卡片仍只是 `?preview=dictionary` 的开发视觉预览。

## 四点调整

1. **纸面与正文扩大**
   - 纸面：`min(1560px, calc(100vw - 48px))`；实测 1920/1440/1366 下为 1560/1392/1318px。
   - 正文：标准 `clamp(820px, 46vw, 900px)`，宽松 `clamp(880px, 50vw, 940px)`；实测 1920 标准 883px，1440/1366 标准 820px。
   - 保留 660/720 的用户设置值不变，只改显示宽度映射；没有改后端校验或数据结构。
   - 底栏宽度限制为 `calc(var(--text-width) + 96px)`，翻页按钮不会被推到纸面最边缘。

2. **书名清晰化**
   - 顶栏 60px → 74px。
   - 书名从 15px 无衬线改为 Georgia 22px / 600，当前章节 10px 大写；实测 computed `font-size: 22px`、`font-weight: 600`。

3. **右侧工具栏放大**
   - 按钮 44px → 54px，图标 21px → 24px，外层改为半透明纸色胶囊、圆角 999px、轻阴影。
   - 实测按钮 `54×54`、3 个入口、位于正文右侧约 16–30px，不再使用低透明度的“看不太见”状态。
   - 收藏仍因 M06 未接入而禁用，保留 Hover 名称。

4. **移除百分比与常规保存状态**
   - 删除“全书 x%”及 `pct` 计算。
   - `SaveStatus` 只在 `unsynced` 时显示“未同步 · 重试”；`idle / saving / saved` 全部不渲染。
   - 底栏实测文本为 `第 1 / 4 页`，不存在 `%`、`全书`、`保存中`、`已保存`。
   - 冲突仍保留纸面内两选一卡片；真实失败不能被静默隐藏。
