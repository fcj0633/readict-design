## 比较历史与修复

初版对照见 `comparison-pass1.png`、`dictionary-initial.png` 和 `reader-initial.png`。发现并修复：

1. [P2，排版] 辅助文字与工具栏图标偏小。增大词义、原文语境与辅助文字，工具栏图标统一尺寸，并为窄屏主要操作增加 44px 点击区域。
2. [P2，主题] shadcn 默认按钮样式没有映射全部自定义主题状态。增加显式 variant 标识与主题变量映射，修复深色按钮及悬停/选择色。
3. [P2，交互] 收藏成功提示可能遮挡词典操作。提示移至右下方，提示主体不拦截页面操作。
4. [P1，位置恢复] 初始化时保存第一页覆盖已有偏移。等待页面状态与排版结果一致后保存，恢复后再改变字号仍保留原位置所在内容。
5. [P3，图标] 收藏与设置图标统一为源稿中的星标与齿轮。

修复后重新获取实际浏览器截图，生成同状态全视图与局部并列证据，再次检查。以上无未解决的 P0/P1/P2 问题。

## 五项视觉检查

| 检查面 | 结果 |
|---|---|
| 字体与排版 | 英文正文 Georgia 默认 20px/1.8；章节标题与词条使用衬线层级，中文操作使用系统无衬线字体。长句允许换行，词典内部滚动。 |
| 布局节奏 | 暖白阅读画布、米灰背景、独立右侧工具栏和浮动词典保留选定方向；正文最大 660px，宽松 720px，打开卡片无位移。 |
| 颜色与状态 | 暖/白/深三套主题、目标词高亮、焦点、按钮选择与禁用状态均检查。辅助文字对比度最低约 5.25:1，正文最低约 10.98:1，设置按钮最低约 5.25:1。 |
| 素材与图标 | 阅读界面没有需补齐的位图装饰；图标使用 Lucide。书架采用真实封面图片，来源已在 README 记录。 |
| 文案与内容 | 使用“收藏”，没有复习或学习库入口；上一页/下一页正确；词典不添加额外例句；主释义及两条其他释义默认可见；原文语境独立显示。 |

有意保留的实现差异：遵循 PRD 将正文严格居中限宽；卡片根据真实选词位置出现，而非固定在概念图坐标；页数取决于实际样书及布局；补充 Mock 来源标识、当前词义选择反馈和真实首尾页禁用状态。概念图的纸面渐变/生成纹理不用于产品。

## 实际运行与检查结果

- React + TypeScript + Vite；Tailwind CSS v4；shadcn/ui（Base UI）；Floating UI；Lucide；React Router；Sonner。
- 官方 Playwright MCP 通过项目内可复现脚本启动 `--isolated --headless --browser chrome`。现有 MCP 浏览器目录被占用，因此没有终止或改动其他浏览器会话。
- 主要流程：41 项浏览器断言通过，记录为 [核心检查记录](evidence/browser-check-results.json)。
- 补充检查：16 项浏览器断言通过，记录为 [补充检查记录](evidence/browser-integrity-results.json)。
- 浏览器记录中的脚本异常 0、控制台错误 0。
- 5 项独立服务测试通过；TypeScript 与生产构建通过；静态检查无警告。
- 生产依赖审计为 0 个已报告漏洞。未执行强制降级或破坏性依赖升级。

覆盖：1440×900、1920×1080、1366×768、390×844；左/右/底部锚点；长释义与长原句；翻译加载与失败；查询无结果与重试；快速选词与关闭后迟到响应；收藏主体/语境归并；搜索；模拟导入；删书保留收藏；刷新恢复；字号变化后的定位；键盘查词与翻页；减少动态效果；本地记录损坏和禁止写入。

分页完整性：第一章 440 个词，在三种受测布局下逐页检查，均覆盖 440 个唯一偏移，没有缺失和重复。
