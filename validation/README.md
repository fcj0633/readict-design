| 分类 | 入口 | 用途 |

| UI 验收 | [2026-11-18 报告](ui/2026-11-18/report.md) | Mock 界面的布局与交互验证；证据在相邻 evidence |

UI 新输出默认在原型 .artifacts/ux 中，确认归档时复制选定证据到新的日期/运行目录并建立报告。已有技术实验 evidence 为历史基线，重跑前先保存并按日期归档新结果，防止报告与证据错配。临时测试目录和依赖不提交。
