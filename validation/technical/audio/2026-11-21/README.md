# 当前音频资源的解码与播放验证

日期：2026-11-21（Asia/Shanghai）。范围：现有发音文件的读取、Speex解码、MP3转换和浏览器媒体引擎播放。**不修改系统设计、M02执行文档或开发计划，不开发正式音频功能，不连接数据库。**

## 结论

**样本技术链路可用：当前发音包可以通过现有6.0.6适配器读取，离线转成MP3后，在Chrome和Edge中完成点击播放、时间推进和播放结束。** 本轮94条英美音样本全部通过读取、解码、转码和再次解码；两个浏览器各94次基础播放全部通过。

原始Ogg/Speex不是本次浏览器可直接播放的格式：使用正确audio/ogg类型的真实样本，Chrome和Edge均返回媒体错误4（DEMUXER_ERROR_COULD_NOT_OPEN）。不能只改扩展名或MIME就当成MP3。

本结论只覆盖所测样本和浏览器媒体引擎。**人工试听、扬声器物理输出、全部录音的完整性以及发音／口音准确性尚未确认。** 浏览器采用headless模式，Playwright默认带有mute-audio启动参数；播放事件和时间推进不是人耳听到声音的证据。试听产物已保留供人工确认，不能将本报告写成完整发音需求或M02验收通过。

## 样本和转换结果

复用M02固定50词清单，不更换缺失词。47词在发音索引中命中，得到94条英美音链接，均成功取出资源；books、reads、runs没有直接索引。此次不实施词形回退，不把这三个词换成别的词后宣称全覆盖。样本包含book、run、ran、running、child、children、saw及其他代表词，完整列表见[逐样本记录](samples.csv)。

| 项目 | 实际结果 |
|---|---|
| 原始格式 | Ogg/Speex、单声道 |
| 源采样率分布 | 11025Hz：46条；16000Hz：48条 |
| 资源读取 | 94/94成功，缺失／重复映射错误0 |
| 原始录音实际解码 | 94/94成功，输出PCM并检查非空、时长和信号 |
| MP3转换 | 94/94成功，单声道、22050Hz、48kbps |
| MP3再次解码 | 94/94成功，输出采样率／声道正确且非全静音 |
| 源PCM时长范围 | 约0.406～1.560秒 |
| 两次解码时长最大差 | 约0.023991秒，小于本轮80毫秒／5%容差门槛 |
| 源PCM RMS范围 | 约-27.220～-10.983 dBFS |
| 命令失败／信号与时长门槛失败 | 0／0 |
| 转换及信号核对耗时 | 28.23秒，仅此次本机样本结果 |

没有自行重写11025Hz源头信息；FFmpeg实际解码得到的源采样率仍为11025Hz。MP3使用显式重采样参数，不能将重采样描述为提升原始录音质量。

FFmpeg对94条源均出现 `Guessed Channel Layout: mono` 警告；源头和ffprobe均表明单声道，命令均正常完成。日志警告不是零条，不能把“无命令失败”表述成“完全无警告”。

本轮信号门槛为PCM非空、RMS大于1e-5、源峰值大于0.001、时长大于0，以及目标采样率／声道正确。时长差容差为max(80毫秒,源时长5%)。这些是可复核的自动检查，不是音质、读词内容或口音的人工评定。源／MP3中接近满幅的采样最大比例分别约0.2734%／0.1530%，原始统计见摘要，不宣称没有削波或失真。

94条原始压缩资源共198475字节，MP3共473805字节，约2.39倍。当前参数提高了本机浏览器可播放性，**没有节省存储空间**，不能从此样本推算全库确定大小。

## 浏览器实际播放

临时HTTP服务仅监听127.0.0.1，提供本地测试页和样本，未访问正式后端。每个样本均通过Playwright实际点击按钮触发HTMLAudioElement.play，检查playing事件、正向currentTime／timeupdate和ended事件；不是仅检查canPlayType或loadedmetadata。

| 浏览器 | 版本 | 基础MP3播放 | 附加检查 |
|---|---|---|---|
| Google Chrome | 157.0.8103.80 | 94/94通过 | book美音连续两次、英音一次通过；播放中切换英音通过；暂停后180毫秒时间不再推进 |
| Microsoft Edge | 157.0.4341.60 | 94/94通过 | 同上，均通过 |

基础播放共188次，失败0；重复播放和切换等附加检查单列，不混入94条样本数。播放中切换时，旧美音未继续触发ended，新英音正常结束。暂停检查在当前样本结束前执行，paused=true、时间变化0、ended=false。

附加检查针对本地验证页的原生播放器，不代表正式阅读器已经具备关闭卡片／翻页取消播放能力。Firefox、Safari、移动设备、真实产品会话鉴权、缓存和Range请求不在本轮范围。

原始Speex以正确audio/ogg Blob测试，两浏览器均返回错误4；该预期不支持结果单列，不能隐去或混算成MP3播放失败。详细记录见[浏览器结果](browser-results.json)。
