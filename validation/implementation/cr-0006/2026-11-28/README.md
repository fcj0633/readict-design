## 实际实现

- 卡片：按真实 sense / rawPos 展示，默认 3 组，更多向下展开；标题使用 lemma，删除词头行和 resolvedLemmaKey；卡片一次定位、内部滚动；父页面与 iframe 空白关闭；Esc/X 保留。
- 收藏：两态 `NOT_FAVORITED/FAVORITED`，首次收藏只写一个附属例句，不追加入口；再次点击直接取消，无确认；回执重放不复活。
- 收藏页：紧凑单词列表，2～3 组释义、真实音标、独立真实发音、详情、直接取消；无句子 tab、时间、语境数、回原文。
- 详情：完整真实释义组与全部历史附属例句，静态书名，无跳转/章节/翻译/复习。
- 认证：登录、注册、找回密码默认手机号，手机号按钮在第一位；后端认证规则不变。
- V10：删除收藏专用定位列，仅保留句子、词面、句内偏移、书名快照与历史翻译字段；回执 `context_id` 置空并改为两态 JSON；V1～V9 未改。

## 实际数据核对

对授权本机活动 COL 数据只读抽查：

- `accept`：3 个重复 source record，每个 10 个原生释义组；rawPos 为 `V-T/V-I`、`V-T` 等；一个 sense 是完整组。
- `good`：一个 source record 下 4 个 region、27 个 sense。
- `run`：2 个重复 source record，各 53 个 sense。
- `bank`：2 个重复 source record，各 3 个 region、12 个 sense。

因此没有修改 `extract.mjs`、bundle、词典导入或 READY 数据。前端和后端按实际数据先选一个 source record，再聚合该 record 内全部 region；这是对技术文档“聚合全部 lemmaKey region”的必要修正，否则 `accept`/`run` 会重复显示。
