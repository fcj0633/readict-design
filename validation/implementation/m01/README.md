## 实施范围与实际依赖

保留 Java 21.0.10、Spring Boot 4.1.2、MP Boot 4 Starter 3.5.18、已有 UUID／UTC 处理器、Problem Details 和数据库保护。Session JDBC Starter 由原 Boot BOM 管理，实际 Spring Session JDBC 4.1.1、Security 7.1.2；未升级工程基线。前端保留 React 19.3.1／Vite 8.3.8，新增精确锁定 React Router DOM 7.18.5，安装、类型检查、构建及实际路由运行通过。系统为 Windows 11，Maven 3.9.14、Node 24.14.0／npm 11.9.0，MySQL 8.0.44。

交付注册、JSON 登录、当前用户、JDBC Session、CSRF、退出、改密、个人设置，以及本地联系方式验证和密码恢复。手机号固定展示 +86，兼容 11 位和 +86 完整号码，共用规范化／唯一键／HMAC 限流。仅格式校验，不代表归属已验证。其他地区、0086、重复前缀、内部空格或连字符、全角数字在后端拒绝。没有增加地区参数、JWT、书架、阅读或联系方式换绑。

密码使用带 `{pbkdf2-r1}` 版本前缀的 PBKDF2-HMAC-SHA256，16 字节随机盐、600000 次迭代、256 位输出；8～128 Unicode code point、UTF-8 不超过 512 字节、至少一位 ASCII 数字与英文字母，不 trim、不归一化。最后一轮本机采样，两次编码加两次匹配合计 **1489ms**，仅本机负载下的粗测，不是吞吐或生产参数保证。密码计算并发设上限；未知账号做等价密码匹配。

Session 主体仅保存 UUID、authVersion、认证时间及必要身份；空闲 30 分钟、绝对 7 天，每次认证请求复核账号状态／版本。JSON 登录显式保存共享 SecurityContext，轮换 Session ID／CSRF；POST LogoutFilter 清理并返回 204。改密与重置提交后，旧会话新请求立即因版本不符失效，物理清理失败只记录重试。开发 Cookie 为 HttpOnly、SameSite=Lax、Path=/、非 Secure（回环 HTTP）；没有将此配置宣称为生产部署。

设置使用 `/api/v1/me/settings`，用户 ID 从认证主体取得；用户锁后设置锁、版本条件更新、仅最后一次请求的幂等识别。前端 500ms 防抖、串行保存，网络不确定时保留原请求和草稿，冲突须用户选择，迟到响应不覆盖新编辑。AuthProvider 区分检查／访客／已登录／服务不可用，取消私有请求，跨标签页同步退出。

## 数据库与秘密管理

V1 原字节未修改。V2 新建用户与设置，V3 原样取实际 Session 4.1.1 JAR 的 `schema-mysql.sql`，V4 新建挑战、恢复凭证和限流桶；Session 自动建表关闭。真实集成测试与浏览器验收使用 **readict_test**，只用 test 专用 app／migrate 账号。测试库已完成 V1～V4，重复启动和 checksum 校验通过，共九张预期表。开发库将在正常 dev 启动时由 Flyway 增量迁移，本次未用开发库注册验收账号。

数据库凭据仍保存在忽略的受限 `.local/database.json`；另生成两个独立 32 字节安全随机秘密，保存为忽略的受限 `.local/auth.json`。限流 HMAC 必需，缺失拒绝启动；验证 HMAC 与限流秘密分开。普通单测用公开的固定测试密钥，不读取真实凭据。没有提交凭据、outbox、原始 Cookie、验证码、恢复 token、一次性验收脚本或临时日志。

默认 Sender 不可用，已存在／未知账号均明确返回 503，浏览器不进入虚构的“已发送”步骤。本地捕获 Sender 仅测试进程内可读；dev outbox 须 dev、回环、显式 local 开关和验证密钥同时满足。outbox 当前用户专有 ACL，随机文件名，不带联系方式，最多 100 文件、10 分钟保留。无公开取码接口。DEV_LOCAL 验证成功始终 simulation=true，真实 verified 仍为 false；非本机配置拒绝本地 Sender。

挑战：安全随机六位码、带挑战／用途／代数的 HMAC 摘要、五分钟有效、最多五次错误、60 秒冷却；目标与 IP 持久限流、稳定目标锁防跨窗口竞争。异步发送有界，SENDING 超时转 UNKNOWN，不延长有效期、不重发；迟到结果按状态条件更新。恢复证明换取一次性高熵 token，只保存摘要，消费／改密／版本／材料作废同事务。测试时禁用后台过期清理，避免可控 Clock 影响其他测试对象。
