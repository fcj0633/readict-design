# A02 本机音频 MVP 实施记录

日期：2026-11-23。状态：本机音频 MVP 核心已启用，最小真实鉴权播放检查通过；完整复验后置。

本轮按用户最新指示优先交付基本可用的 MVP，不再执行完整验证。原 A02 计划的全面复验目标保留为后续清单；不更换音源，不增加 TTS，不提前开发 M05 正式卡片。

## 已交付实现

长期 Node 音频检查／转换／校验工具、独立 readict-audio-bundle-1、V6 四表、私有媒体发布、可续跑离线导入与版本条件激活、AudioCatalog 内部查询，以及使用现有 Session 的 GET／HEAD 播放接口。保留 Web 与 dictionary-tool 两个 JAR，离线命令不加载账号任务且不需要认证 HMAC。V1～V5 不修改，文字词典身份和活动指针不改变。

文件工作采用 4 个线程、最多 16 个在途任务；冻结清单，媒体在最终私有发布时逐文件校验并原子改名，省去整库中间副本；READY 复用发布结果并核对数据库计数，激活复用 READY 的数据库计数与版本。播放按需校验摘要，所有已提交文件任务结束后才清理暂存。逐文件强制同步刷盘、断电恢复和独立全库巡检后置。数据库仍最多 500 行／2MiB 参数一个批次，断点同事务，租约 120 秒、30 秒心跳。READY 不自动激活。

## 使用范围与后续

本机 LOCAL_MVP 采用，不代表完整音源零缺陷、完整 A02 验收或分发授权。正式卡片、换词／翻页等播放生命周期待 M05；人工试听 NOT_PERFORMED，数据权利 UNVERIFIED，snapshotAllowed=false、distributionAllowed=false、releaseEligible=false。

本机忽略目录已准备 20 词／40 条录音的 WAV 与 MP3 对照试听材料；所有 review 仍为 NOT_LISTENED，不登记 AT10 通过。原音频、MP3、WAV、全文清单、工具二进制、秘密和一次性脚本不提交。

后续按实际产品需要补完整复验、扩展双声道输入支持及人工试听；不以这些优化阻塞本轮最小可用底座。

运行过程补记：Windows 同摘要录音并发发布时会出现 AccessDeniedException，已改为仅在目标是完整、摘要一致的文件时幂等复用，其他权限错误继续失败。发布失败时尚未注册 READY 数据集。被中断旧导入留下的本机临时目录清理被自动审批以“策略阻止”拦截，目录暂留，不影响最终私有存储或源包；不改用其他方式绕过该拦截。
