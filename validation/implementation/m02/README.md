## 已实际交付

应用新增长期离线工程 tools/dictionary-import：Node 24 ESM、js-mdict 6.0.6、parse5 8.0.0、精确锁文件与自建 HTML／MDX 测试夹具。不加载浏览器、数据库、凭据或常驻服务。

inspect 对完整 MDX／MDD 计算原始文件摘要，逐条读取、严格解码、复核输入未变化；按物理 key-block 顺序保留每个索引位置。6.0.6 的 keywordList 会无条件重排，不能直接当源顺序；适配器重新读取各 key-block，并用下一源位置计算记录结束。库的单记录读取不能覆盖跨 record-block 范围，适配器通过公开 API 读取完整块后拼接；自建 MDX 测试包含跨块的 UTF-8 多字节记录和同 key 不同内容。

diagnose 提供完整源处置、问题和固定50词候选输出。col-extract-r2 支持 h4/span.title、wt-container 多区域、独立中文翻译节点、中文段落和完整英文句结束分隔的混排版式；忽略多区域预览标题，剔除脚本／资源／嵌套例句，保留 IPA 和源义项顺序。无释义的 see-also 引用不作为释义。无法确认边界、缺字或结构时整条源记录 FAIL，不保留半成功区域，不按第一个汉字截断或编造译文。

normalize 是提取词头比较键的 Node 辅助实现；**尚未完成 Java 一致性向量和正式词形解析**。diagnose 始终退出3、diagnosticOnly=true、releaseEligible=false，不生成正式 manifest。中断保留.partial，已有目录拒绝覆盖。正式 convert／validate、确定性数据集身份、V5、Java 工具和 DictionaryProvider 均尚未交付；不以诊断代替这些目标。
