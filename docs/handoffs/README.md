# 开发交付基线

本目录用于将确认的设计和验证结论交给独立的 readict-app 仓库。当前开发仓库仅初始化 Git，尚未发布正式开发基线。

使用 [交付模板](../../templates/development-handoff.md)，文件命名 `BASELINE-0001-主题.md`。交付必须列出需求版本、批准变更、设计、ADR、验证及其所在 Git 提交，明确已验证能力、未决阻断项和验收标准。实际开发提交通过基线编号与设计仓库提交建立追溯关系，不依赖两仓库必须位于同一绝对路径。
