## 1. 目标、范围与取舍

### 1.1 本轮主链路

**已登录用户 → 阅读并点词 → 卡片显示真实词典 → 收藏单词及当前原句 → 收藏页按单词／句子回看 → 回原文并验证内容 → 取消收藏。**

本轮把 M05 卡片中的收藏占位改成真实操作，并完成收藏持久化、快照、列表、搜索、筛选、详情、原文返回和书籍删除后的保留。收藏以 lemma 为主体，不按词性或词义拆分。

### 1.2 本轮交付

| 交付 | 说明 |
|---|---|
| V9 三表 | `user_favorite_word`、`favorite_word_context`、`mutation_receipt`；不改 V1～V8 |
| 收藏写入 | 首次建主体、同词追加句子、同位置去重、三态返回、首次快照不覆盖 |
| 收藏查询 | 单词／句子视图、搜索、来源筛选、稳定游标、详情、来源列表 |
| 取消收藏 | 整主体删除、级联语境、幂等、确认交互、旧请求不复活 |
| 书籍删除 | DELETING 时拒绝新收藏，解绑 book/chapter 但保留全部快照 |
| 卡片接入 | 收藏／收藏本句／已收藏三态、保存中／失败、卡片不关闭 |
| 回原文 | 从收藏详情恢复真实位置；源不可用则只显示快照，不伪造跳转 |
| 验证 | 本机 `readict_test` 事务并发、两用户隔离、删除竞争、HTTP 鉴权、浏览器流程 |

### 1.3 明确不做

- 不做复习、复习队列、间隔重复、学习进度。
- 不做同一单词的多词性／多义项收藏管理；只保存首次收藏的主要释义快照。
- 不做独立“句子收藏”；句子只能作为单词主体的语境。
- 不做收藏导出、跨设备同步、收藏分享。
- 不实现 M07 翻译；本轮 `translation_id` 及译文快照字段允许为空，M07 再补完整链路。
- 不把词典全量或可再分发的词典快照写入收藏；只保存用户首次收藏所需的最小释义／词性／音标及身份引用。
- 不做真实个人 EPUB 的提交；测试样书不入库。

## 3. 领域规则

### 3.1 收藏主体

- 唯一键：`(user_id, lemma_key)`，二进制比较，不含 POS、senseId 或 bookId。
- `lemma_key` 来自 M05 查询 receipt 的已确认 lemma；无法确认 lemma 时使用规范化 surface 作为回退标识，并记录 `lemma_method=SURFACE_FALLBACK`。
- 主体保存首次收藏的：lemma、首次原文词形、IPA（有则保存）、主要词性、第一条主要中文释义、词典 provider/version、dataset/entry/sense 身份、lemma method、normalization version、收藏时间。
- 再次收藏同一 lemma 不覆盖上述快照；不同词性／不同义项不新建主体。
- `NOT_FOUND`／`UNSUPPORTED_QUERY` 不得作为首次收藏的合法词条；如果已有主体，且来源可验证，允许 `favoriteId + source` 追加语境。

### 3.2 语境与去重

语境唯一键：`(favorite_word_id, context_key)`。服务端从已校验来源和 `book.origin_key` 重新计算 `context_key`：

```
sha256(
  len(originKey)||originKey ||
  len(pipelineVersion)||pipelineVersion ||
  len(artifactHash)||artifactHash ||
  len(spineHref)||spineHref ||
  len(blockId)||blockId ||
  int32(sentenceStart) || int32(sentenceEnd)
)
```

- 长度前缀使用 UTF-8 字节长度；整数使用 big-endian 4 字节；所有字段使用规范值。
- `context_key` **不包含** wordStart/wordEnd、surface、quote、书名或 chapter；同一句点击不同词位置不新增语境，保留首次目标词范围与词形。
- 同一 `originKey`、artifact、pipeline、spine、block、句范围才算同一处；同文不同书、不同位置、不同 pipeline 不合并。
- 不同 lemma 可以各自关联同一句；不做独立句子收藏。
- 删除书籍后保留 `originKey`、sourceHash、artifactHash、pipelineVersion、书名／章节名快照和句子；`book_id/chapter_id` 置空。

### 3.3 快照与翻译

- 原句、word 范围、surface、来源、首次词义不可变。
- 句子最长 10000 UTF-16 单元；单词范围最长 128；CFI 最长 4096 字节；超长不静默截断，返回 `SOURCE_TOO_LONG` 并保留阅读。
- `translation_id/translation_snapshot/translation_provider/translated_at` 本轮可为空；M07 仅在原译文为空时写入，重复请求或缓存刷新不覆盖已保存译文。
- 释义快照只用于用户收藏展示，不是可公开分发的词典包；遵守 M02 `snapshotAllowed=false` 与数据权利。

### 3.4 三态与取消

| 状态 | 卡片按钮 | 点击行为 |
|---|---|---|
| `NONE` | 收藏 | 创建主体＋当前语境 |
| `WORD` | 收藏本句 | 复用主体，追加当前语境 |
| `CONTEXT` | 已收藏 | 打开整主体取消确认 |
| 加载中 | 收藏状态加载中 | 禁用 |
| 保存中 | 保存中… | 禁用，防重复提交 |
| 保存失败 | 重试收藏 | 使用原 requestId 重试，不显示已收藏 |

取消确认文案必须说明“删除该单词及全部 N 条原文语境”；确认后删除主体并级联语境，不删除书籍、公共词典或其他主体。取消后卡片回到 `NONE`，但不关闭卡片。

### 3.5 书籍删除

- M03 删除事务先将 book 置 `DELETING`；M06 在同一事务调用 `FavoriteRepository.detachBook`，将该书语境 `book_id/chapter_id` 置空并保留快照。
- 新收藏在书籍 `DELETING`／非 READY 时返回 `BOOK_DELETING`／`BOOK_NOT_READY`。
- 物理清理删除 book/chapter 时由 `ON DELETE SET NULL` 兜底；收藏详情仍可读，`sourceAvailable=false`，回原文链接禁用。
- 同一 sourceHash 重新导入是否重新关联孤立语境，M06 不自动猜测；必须后续显式迁移并验证 artifactHash／pipelineVersion／anchor。M06 只保证不丢快照、不崩溃、不显示可点击的错误来源。

## 5. M05 receipt 扩展（M06 前置）

M05 当前 receipt 只有 entryIds/senseIds，M06 不能从客户端或当前活动词典重新猜测首次快照。M06 开始前扩展 `LookupReceiptStore.Receipt`，保留：

- `source`（已规范）、`datasetId/datasetVersion/normalizationVersion/provider/policyVersion`；
- 选中 entry 的 `entryKey`、`headword`、`lemma`、`lemmaKey`、`lemmaMethod`、`ipa`、`pos`、`meaning`；
- `senseKey`（服务端选择的 sense 身份）；
- 选中 region 的 entry/sense IDs；
- 原 `lookupId` 10 分钟 TTL、进程内容量限制。

M05 响应可继续返回 `favoriteState=null`；M06 新增 `GET /favorites/state` 使用 receipt，不要求 M05 lookup 响应改字段。进程重启后 receipt 丢失，state/save 返回 `410 LOOKUP_EXPIRED`，前端重新查词；M06 不把 receipt 持久化到数据库。

## 6. API

统一前缀 `/api/v1`；除 GET 外需要 CSRF；所有资源从当前 Session 取用户，跨用户 ID 返回 404；响应私有数据 `Cache-Control: no-store`；错误使用 Problem Details。

### 6.1 三态查询

`GET /api/v1/favorites/state?lookupId={uuid}&senseId={provider-sense}`

```json
{
  "state": "NONE",
  "favoriteId": null,
  "contextId": null,
  "contextCount": 0
}
```

- `senseId` 必须是 receipt 中候选义项；使用 receipt 的 source 和该 sense 所属 lemma 计算 contextKey，查询当前用户主体与该语境。歧义候选切换后前端重新请求 state；缺失/不属于 receipt 返回 400 `INVALID_REQUEST`。
- `NONE`／`WORD`／`CONTEXT`；receipt 过期 `410 LOOKUP_EXPIRED`；跨用户 receipt 404。
- 卡片打开并完成 lookup 后调用；歧义候选切换后重新调用；失败时按钮禁用并显示原因，不显示假“未收藏”为可操作。

### 6.2 保存

`POST /api/v1/favorites`，请求头 `Idempotency-Key: UUID`，body：

```json
{
  "lookupId": "e0000000-0000-4000-8000-000000000001",
  "senseId": "provider-sense-1",
  "source": {
    "artifactId": "a0000000-0000-4000-8000-000000000001",
    "spineHref": "OEBPS/Text/ch1.xhtml",
    "blockId": "b-17",
    "sentenceStart": 0,
    "sentenceEnd": 46,
    "sentence": "The children are running toward the old house.",
    "surface": "children",
    "wordStart": 4,
    "wordEnd": 12,
    "wordRangeCfi": "epubcfi(/6/2!/4/4,/1:4,/1:12)",
    "sentenceRangeCfi": "epubcfi(/6/2!/4,/2/1:0,/4/1:46)",
    "quote": {"exact": "The children are running toward the old house.", "prefix": "", "suffix": ""}
  }
}
```

- 首次收藏必须带 `lookupId + senseId`；服务端从 receipt 取 lemma/快照，不信任客户端 lemma。
- 已确认 lemma 的 receipt 才可用于首次收藏；`NOT_FOUND/UNSUPPORTED_QUERY` 首次收藏返回 `409 FAVORITE_WORD_UNAVAILABLE`。
- 已存在主体、当前原文可验证且词典暂时不可用时，允许 `{favoriteId, source}`，不带 lookupId/senseId；服务端必须用现有词形规则确认 surface 可归入该主体，否则 `409 LEMMA_UNCONFIRMED`。
- 请求 source 必须与 receipt 的 artifactHash/pipeline/block/sentence 一致；字段级不符 `422 SOURCE_INVALID`。
- 服务端从索引重建书名、章节名、原句、word range 和 quote；不采用客户端文本作为最终快照。
- 成功返回：

```json
{
  "favoriteId": "f0000000-0000-4000-8000-000000000001",
  "contextId": "c0000000-0000-4000-8000-000000000001",
  "lemmaKey": "child",
  "state": "CONTEXT",
  "createdWord": false,
  "createdContext": false,
  "contextCount": 2,
  "resourceState": "active"
}
```

- 重复保存同 requestId + 同内容返回原结果，`createdWord/createdContext=false`；同 key 不同内容 `409 IDEMPOTENCY_KEY_REUSED`。
- `favoriteId` 已被取消后重放旧 save 请求：返回原 IDs 与 `resourceState:"deleted"`，不重新插入；前端刷新 state 后显示未收藏。

### 6.3 列表与来源

`GET /api/v1/favorites?view=words|sentences&q=&source=&sort=recent|old&cursor=&limit=20`

- `limit` 1～100，默认 20；`cursor` 为服务端生成的 opaque 值（内部 `(created_at,id)`）。
- `source` 为 `originKey`（不是 nullable book_id）；已删除书仍可筛选。
- 搜索参数化 `LIKE`；转义 `%`、`_`、`!` 并使用 `ESCAPE '!'`；单词匹配 lemma，句子匹配 context EXISTS。搜索不声称全文索引。
- words 投影：

```json
{"id":"...","lemma":"child","ipa":"/tʃaɪld/","pos":"noun","meaning":"小孩","contextCount":2,"createdAt":"..."}
```

- sentences 投影：

```json
{"contextId":"...","favoriteId":"...","lemma":"child","sentence":"...","wordStart":4,"wordEnd":12,
 "bookTitle":"...","chapterTitle":"...","sourceKey":"...","sourceAvailable":true,
 "bookId":"...","anchor":{...},"createdAt":"..."}
```

- 响应 `{items, nextCursor}`；无结果 200 空数组，不用 404。
- `GET /api/v1/favorites/sources` 返回用户来源：

```json
{"items":[{"originKey":"...","bookId":"...?","bookTitle":"...","sourceAvailable":true,"contextCount":2,"lastCreatedAt":"..."}]}
```

来源按 `originKey + 书名快照` 分组；`bookId` 可空；不返回其他用户来源。

### 6.4 详情

`GET /api/v1/favorites/{favoriteId}` 返回主体完整快照与全部 contexts：

```json
{
  "favorite": {"id":"...","lemma":"child","ipa":"...","pos":"noun","meaning":"...","contextCount":2,"createdAt":"..."},
  "contexts": [{
    "contextId":"...","sentence":"...","wordStart":4,"wordEnd":12,"surface":"children",
    "bookTitle":"...","chapterTitle":"...","sourceAvailable":true,"bookId":"...",
    "anchor": {"artifactId":"...","artifactHash":"...","pipelineVersion":"...","spineHref":"...","cfi":"...","quote":{...}},
    "translation": null,"createdAt":"..."
  }]
}
```

- 跨用户 404。
- `sourceAvailable=false` 时不返回可点击 `anchor` 或返回 `anchor:null`；前端必须禁用“回原文”。
- 详情只访问收藏主体及其语境；不允许用 contextId 直接跨主体查询。

### 6.5 取消

`DELETE /api/v1/favorites/{favoriteId}`，需 CSRF；建议带 `Idempotency-Key`。

- 删除主体，级联删除全部 contexts；不删除 books、公共词典、其他主体。
- 已不存在仍 `204`；跨用户 404。
- 与保存的锁顺序见第 8 章；旧 save 重放按 6.2 返回 `resourceState=deleted`。

### 6.6 错误码

| 状态 | code | 场景 |
|---|---|---|
| 400 | `INVALID_REQUEST` | UUID／字段格式、limit／cursor 非法 |
| 401 | `UNAUTHORIZED` | 未登录 |
| 403 | `CSRF_INVALID` | 缺少／错误 CSRF |
| 404 | `FAVORITE_NOT_FOUND` | 不存在或跨用户 |
| 409 | `BOOK_DELETING`／`BOOK_NOT_READY` | 新收藏来源不可写 |
| 409 | `LEMMA_UNCONFIRMED` | favoriteId 追加但无法确认词形 |
| 409 | `IDEMPOTENCY_KEY_REUSED` | 同 key 不同内容 |
| 410 | `LOOKUP_EXPIRED` | lookupId 过期／服务重启 |
| 422 | `SOURCE_INVALID`／`SOURCE_TOO_LONG` | 来源重建或长度失败 |
| 503 | `DICTIONARY_UNAVAILABLE` | 首次收藏需要词典但不可用 |

## 7. 后端实现建议

建议包与类（名称可收敛，不建空层）：

- `favorites/api/`：`FavoriteController`、`FavoriteDtos`、`FavoriteProblemAdvice`（如需）。
- `favorites/application/`：`FavoriteService`、`FavoriteSourceValidator`（复用 M05 source/index 逻辑）、`ContextKey`、`FavoriteProjection`。
- `favorites/infrastructure/persistence/`：`FavoriteWordMapper`、`FavoriteContextMapper`、`MutationReceiptMapper` 及 XML。
- `favorites/domain/`：`FavoriteState`、`FavoriteSnapshot`、`FavoriteDraft`。
- 修改 M05：`LookupReceiptStore` 增加收藏草稿字段；`LookupService` 创建 receipt 时填充；M05 测试补字段。
- 修改 M03：`ImportService.requestDelete` 事务中调用 `FavoriteRepository.detachBook`；M06 负责收藏侧 Mapper，不让 Controller 直接访问。

### 7.1 保存事务

1. 校验 CSRF／Session／请求 UUID 与 Idempotency-Key。
2. 从当前用户取 book，锁 book；READY 才可写；`DELETING` 拒绝。
3. 通过 receipt 取 source/lemma/dataset 首义；`lookupId` 过期 → 410；source 与请求字段比对。
4. `FavoriteSourceValidator` 从索引重建 source：artifactHash/pipeline、spine、block、sentence、word range、quote、contextKind；超限拒绝。
5. 计算 `context_key`；开启事务，锁顺序 book → favorite → context → receipt。
6. 按 `(user,lemma_key)` 查主体；无则插入；唯一冲突后重新 SELECT 并加锁；插入失败不能吞掉非唯一 SQL 错误。
7. 插入 context；`UNIQUE(favorite_word_id,context_key)` 冲突后查现有；已存在返回 `createdContext=false`；同一句不同目标不新增。
8. 书名／章节名／source 快照写入；首次快照只在新主体；后续不更新。
9. 写 mutation receipt（同事务）；提交后返回三态。
10. 空主体不提交：首次主体与至少一条 context 必须同事务；任何一侧失败整体回滚。
11. 死锁／瞬时 DB 冲突确认回滚后最多重试两次，短随机退避；不重放外部词典调用。
12. 事务隔离 READ COMMITTED；唯一约束承担去重，行锁承担删除／保存竞争。

### 7.2 删除事务

- `DELETE` 锁 favorite 主体；不存在返回 204；删除主体级联 contexts。
- 与保存竞争：前端串行 mutation；服务端锁顺序 book→favorite→context→receipt。测试 20 并发保存、保存／删除竞争，断言最终状态和约束一致。
- 旧 requestId 的 save receipt 在删除后返回原 IDs + `resourceState=deleted`，不重建。
- 不删除书籍；书籍删除反向解绑 context。

### 7.3 书籍删除

`ImportService.requestDelete` 现有事务顺序：锁书→置 DELETING→删进度→登记清理任务。M06 在置 DELETING 后、登记任务前调用 `detachBook(bookId)`，将语境 book/chapter 置 NULL，保留 origin/source/artifact/pipeline/句子/书名/章节快照；失败回滚整个删除事务。物理删除时 FK SET NULL 兜底；不级联收藏主体。

### 7.4 列表查询

- words：`user_id = ?` + LEFT JOIN 聚合 contextCount；按 `(created_at, id)` 排序；游标参数化。
- sentences：`JOIN favorite_word` 校验用户；按 `(context.created_at, id)` 排序；source filter `origin_key`；已删除书仍返回快照。
- 搜索词 ≤100；`LIKE` 转义；`source` UUID 校验；`limit` 上限 100。
- 查询计划与 `EXPLAIN` 记录；不宣称全文索引。
- 详情按 favoriteId + 用户；contexts 按 `(created_at,id)`。

## 8. 前端实现

### 8.1 卡片

- M05 `DictionaryCard` 收藏按钮从禁用改为真实操作；`GET /favorites/state?lookupId&senseId` 加载三态，歧义候选切换后重新获取。
- 点击 `NONE/WORD`：POST save，按钮“保存中…”禁用；成功保持卡片打开、轻量 toast、刷新 state；失败保留卡片、显示重试，不提前显示已收藏。
- `CONTEXT`：点击打开确认框“删除 [lemma] 及全部 N 条语境”；确认 DELETE；成功后 state NONE，卡片不关闭。
- 保存／删除串行；网络失败使用原 Idempotency-Key 重试；`resourceState=deleted` 时刷新 state，不复活。
- 无 lemma/词典失败：首次收藏按钮禁用并解释；已存在主体时显示“收藏本句”（favoriteId 模式）。
- 收藏状态请求失败不得伪装成 NONE；显示“暂不可用”并允许重试。

### 8.2 收藏页

新增 `/favorites` 受保护路由，账号导航/阅读器工具栏入口；保留阅读器工具按钮的 54px 胶囊视觉。页面：

- 标题、统计（主体数／语境数）。
- 单词／句子 segmented tabs；搜索框；来源下拉（含已删除书）；时间排序；分页“加载更多”。
- 单词卡片：lemma、IPA、POS/释义、语境数、收藏时间、详情、删除。
- 句子列表：原句（目标词高亮）、lemma、书名/章节、来源可用性、回原文。
- 详情：主体快照 + 全部句子 + 翻译（本轮为空）+ 来源状态。
- 空状态：无收藏与无搜索结果分开；删除确认说明全部语境。
- 已删除书：显示书名快照，`sourceAvailable=false`，无“回原文”链接。

### 8.3 回原文

- 详情中的 context 有可用 anchor 才显示链接：`/reader/{bookId}?favorite={favoriteId}&context={contextId}`。
- ReaderPage 读取 query，调用 `GET /favorites/{favoriteId}` 选取 context；再次校验 `sourceAvailable`、当前 active artifactHash/pipeline；通过 `engine.display(anchor)` 恢复，失败用 quote 核验，仍失败回到章节起点并提示，不显示收藏句子已定位。
- 无 source 或 artifact 不匹配时禁用链接；不用同文猜测位置。
- 从阅读器打开收藏页时保留 `from`，返回阅读器不丢当前进度；收藏页不修改进度，除非用户明确回原文。

## 9. 并发、幂等与失败矩阵

| 场景 | 服务端 | 前端 |
|---|---|---|
| 20 并发同词同句 | 唯一约束 + 行锁；最终 1 主体 1 语境 | 只显示一次成功；其余幂等 |
| 同词不同句 | 1 主体 N 语境 | 追加后卡片“已收藏” |
| 同句不同目标 | 同 contextKey，不新增；保留首次范围 | 显示已收藏；不重复 |
| 两用户同词 | 各自主体／语境 | 互不可见 |
| 保存响应丢失 | receipt 同事务＋requestId 重放 | 显示确认中，重试相同请求；不直接判失败 |
| 同 key 不同内容 | 409 | 停止并提示状态异常 |
| 保存／删除竞争 | 锁顺序；旧 save 回执 deleted | mutation 串行；删除后不复活 |
| 书籍删除 | 停止新 source；解绑保留快照 | 入口不可跳；列表显示原书已删除 |
| lookupId 过期 | 410 | 重新查词后收藏；不伪造词条 |
| 词典不可用 | 已有主体可 favoriteId 追加；否则 409/503 | 原文仍可读；首次收藏禁用并说明 |
| DB 不可用 | 不提交成功 | 保留原句；显示可重试 |

## 12. 退出条件

- 同一用户同一 lemma 永远一个主体；同一主体同一 contextKey 一条语境；同文不同位置不误合并。
- 首次词义／词性／音标／词形快照不被后续收藏覆盖；不同词典数据集切换不改历史快照。
- 20 并发同词同句最终 1 主体 1 语境；不同句追加；两用户隔离；取消后旧 save 重放不复活。
- 书籍 DELETING／物理删除后收藏仍可读，book/chapter 解绑，sourceAvailable=false，回原文不可点。
- 列表搜索、来源筛选、稳定游标、详情、取消确认、卡片三态和回原文内容匹配均通过本机浏览器验证。
- `readict_test` 集成测试与 `FoundationIT` 通过；前端 lint/test/build 通过；V9 首次 1 个、二次 0 个迁移（开发库另需批准）。
- 不以“本机 MVP”替代完整收藏验收；未完成的翻译、复习、导出和完整兼容明确列出。

## 13. 风险与待定决策

1. **M05 receipt 扩展**：若不在 M05 receipt 保存首义快照，M06 会在词典切换后保存错误快照；必须先扩展，不能在 save 时重新查当前活动词典。
2. **幂等回执和删除竞争**：旧 save 已提交后删除，回执返回 deleted；未提交的在途 save 与 delete 由前端串行＋锁顺序约束；需用 IT 验证，不能宣称完全线性化。
3. **书籍重新导入**：M06 不自动重连孤立语境；需显式迁移和 artifact/anchor 全匹配，避免错误跳转。
4. **搜索性能**：LIKE 前导通配不命中普通 B-tree；按当前规模接受，不声称全文索引。
5. **翻译字段**：M07 表未建，V9 的 translation_id 无 FK；M07 迁移补 FK，M06 不写入译文。
6. **数据权利**：`snapshotAllowed=false` 仍有效；收藏只保存最小首义快照，不做词典导出或公开分发。
