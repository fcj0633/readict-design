# UX-R01 正式阅读器视觉改版执行说明

日期：2026-11-25。依据：用户选定的“优雅暖色系电子书阅读界面”图片及确认后的改版方案。任务为正式阅读器的视觉和交互收口，独立于 M04 原任务与历史完成条件。

## 目标与边界

让真实 EPUB.js 阅读页形成“轻量品牌导航／纸面书名和章节／主导正文／稳定分页”的层级，改善内部比例、留白、工具栏定位和翻页点击区域。沿用真实书名、章节、页码和用户偏好，不使用模拟段落或写死数据。

正式实现位于平级 readict-app；主要涉及 ReaderPage、ReaderLayout、reader.css、主题规则及必要的阅读交互修复。不得修改 Java 后端、数据库结构、EPUB 导入、CFI／进度协议，不提前实现 M05／M06／M07。词典开发预览、设备朗读和示例翻译仍是预览能力，收藏保持禁用。

## 执行步骤与退出条件

| 步骤 | 操作 | 退出条件 |
|---|---|---|
| UX-R01-01 | 核对源码、端口和真实 EPUB，保存当前页面 | 有本轮改版前截图，未用旧 M04 截图冒充 |
| UX-R01-02 | 顶部品牌／返回、纸面标题、稳定阅读区及分页 | 外层不重复书名；正文与工具不遮挡；标题异步加载不挤动 iframe |
| UX-R01-03 | 正文宽度、用户偏好、主题、面板与窄屏 | 标准／宽松上限约900／1000px，保存值660／720不变；不强制更改字号或默认值 |
| UX-R01-04 | 真实浏览器视觉复核及相关交互修复 | 三桌面、390px、目录／设置／预览／深色有证据，必要调整已复测 |
| UX-R01-05 | 构建、测试、报告和两个仓库提交 | 实际结果可追溯，失败与未覆盖项明确，保留其他工作区修改 |

纸面上限1560px、圆角约14px；品牌栏56px，短屏48px。桌面工具栏在纸面内右上，按钮至少44px；900px以下位于标题下方。上一页描边、下一页深绿、动态页码居中，状态行预留高度。长书名和章节省略并保留完整title。正文不使用scale，不插入包词DOM，不删除书籍自己的章节标题或自然空白。

普通段落基础间距0.65em，不加!important，不统一覆盖作者缩进。字号18／20／22／24和行距1.6／1.8／2继续由用户偏好控制；书籍class或行内排版可能进一步影响实际段落，必须记录实测，不能假装body样式代表所有段落。

## 验证方法

- 浏览器：本机Edge＋Playwright，使用真实导入产物，首轮截图后作视觉复核；不替换真实iframe。记录实际浏览器版本。
- 三桌面：1920×1080、1440×900、1366×768；另测390×844。检查纸面、正文、工具、页脚边界、横向溢出和键盘焦点。
- 目录／设置开关前后比较阅读容器、iframe尺寸、页码及同一iframe身份，不能只看截图。
- 字号／宽度变化和刷新以原文quote仍在可见区为恢复依据，不以页码相同代替定位验证。
- 翻页、章节跳转、iframe内方向键、首尾禁用、返回书架保存均检查；网络失败用定向拦截且明确标注模拟；冲突使用两个真实页面。
- 预览单独用含children的真实EPUB夹具，检查词语锚点、边界及关闭；不将预览当正式查词或真实发音。
- 运行前端lint、普通测试与生产构建。临时脚本留本地忽略目录，应用不新建docs/。

## 运行与证据边界

本轮默认端口被其他项目占用，临时前端5174、后端8081；不停止其他项目。通过本机配置加载器连接readict_test，Flyway目标锁定已有V8；启动保护要求启用Flyway，因此以实际“无迁移必要”日志确认未改变表结构，不能声称禁用Flyway后启动成功。

验收使用独立账号及通过既有API导入的本地EPUB，不清空其他用户数据；偏好结束后恢复初值。原始书籍、凭据、会话和单次脚本不提交。资源保留在本机用于复现，无整库或共享数据清理。
