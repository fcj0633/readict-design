## 1. 目标、取舍与完成边界

本轮开发主链路：**登录 → 打开已导入英文 EPUB → 点击正文单词 → 展示真实 COL 释义与原句 → 点击已有英／美音录音 → 关闭卡片继续阅读**。

按用户已确认的 MVP 优先原则，复用现有可用底座，不补词、不优化全库提取、不重做全量转换、不开展完整兼容与性能验收。保留源码中已有测试，只运行本次必要检查；鉴权、原文归属、偏移正确性、迟到响应隔离和真实录音播放属于必要功能，不能省略。

## 4. 正文选词与原文事实

### 4.1 取词与命中

1. 在 epub.js content hook 内给当前 iframe document 安装事件，并登记销毁函数。排除链接、目录／脚注导航和交互控件；拖动形成选区时不按一次普通点词处理。
2. 优先使用 caretPositionFromPoint，缺失时用 caretRangeFromPoint。仅接受文本节点；通过 Range 实际矩形确认点击命中 token，避免点到行尾空白却选中邻词。
3. 复用 M04 规范块序号、节点与 UTF-16 偏移映射，跨 strong／em／span 保持一个词，不向正文插入逐词 span，不依赖全局文本替换。
4. token 范围是 ASCII 英文字母，可含词内直／弯撇号和连字符；去外围标点只调整词边界，不改正文。`well-known` 整体查询，不拆成多次请求。中文、纯数字、纯标点不查词。
5. 多个 Range rect 时取实际命中的可见矩形。将 iframe 内 rect 按 iframe 边界和实际渲染比例换算到父页 viewport 坐标，滚动／缩放后不能复用旧坐标。

### 4.2 规范块、原句与偏移

客户端先校验块数、UTF-16 长度和未归一化文本 UTF-8 SHA-256，与 M03 的 text-index 一致后才发起带来源的查询。原句直接使用索引中包含词范围的 sentence／fragment，**不新增第二套浏览器分句规则**；保留空白和换行，不先 trim 再套旧偏移。块验证失败时阅读继续，提示无法准确定位，禁止发送虚构来源。

请求 source 沿用系统契约：

```ts
interface SourceContext {
  artifactId: string;
  spineHref: string;
  blockId: string;
  sentenceStart: number; sentenceEnd: number; // 块内 UTF-16，[start,end)
  sentence: string; surface: string;
  wordStart: number; wordEnd: number;         // 句内 UTF-16，[start,end)
  wordRangeCfi: string; sentenceRangeCfi: string;
  quote: { exact: string; prefix: string; suffix: string };
}
```

artifactHash、pipelineVersion 不新增为客户端必填，服务端从所属产物取得并在响应 source 中补齐。contextKind 从服务端索引 SENTENCE／FRAGMENT 转成 sentence／fragment。

服务端按以下顺序校验：认证主体 → book 所有权与 READY → 所属有效产物 → spine／block → 数字及代理项边界 → 索引分句 → 重建 sentence 与 surface。校验不信任客户端正文、lemma、书名和 CFI。CFI 只作为定位提示，不代替索引证据。

计算 `absoluteWordStart = sentenceStart + wordStart`、`absoluteWordEnd = sentenceStart + wordEnd`，范围必须完整落在一个索引句段。canonical source 使用该句段重建；必要时重新计算句内词偏移。客户端句段可以被规范化，但客户端 sentence 必须对应其声称的原始范围，surface 必须精确相等；跨句、越界、切开代理项或伪造文本拒绝。响应取服务端原文，覆盖临时预览。

预算：surface 最多 128 UTF-16 单元且满足既有查询规范；原句最多 10000 UTF-16 单元；spineHref 最多 512 字符、blockId 最多 128 字符；每个 CFI 最多 4096 UTF-8 字节；quote exact 为原句，prefix／suffix 各最多 128 UTF-16 单元且不得切断代理项。其他总请求体沿用应用限制，DTO 必须先验证再访问存储。超限明确报错，不截断；保留阅读。

复用 ReadingIndexCache 时检查并修复其并发访问保护（当前 LinkedHashMap 未同步）；读取不可变 index，不建立新的无界正文缓存。每次重新检查书籍归属与产物状态，缓存不能代替授权。

## 5. 查词接口与内部装配

### 5.1 HTTP 契约

新增 **POST `/api/v1/dictionary/lookups`**，沿用 Session、账号状态／authVersion、X-CSRF-TOKEN 与统一 Problem Details。精确开放此路由，保留其余 denyAll 保护。响应 `Cache-Control: no-store`；日志只留 requestId、状态、耗时，不记录原句或整条词典正文。

请求为 `{bookId,source,posHint?,lemmaCandidate?}`。posHint 仅允许既有 Provider 枚举；本轮前端默认不传，按源顺序展示。lemmaCandidate 为兼容已有契约可接收有界字符串，但**不作为追加查词或归并依据**；仅查询已核验的 surface 及 Provider 的显式映射。未知字段按现有 JSON 策略处理，不能借候选输入执行脚本或任意查询。

响应字段：

| 字段 | 行为 |
| --- | --- |
| lookupId、expiresAt | FOUND／AMBIGUOUS 创建短期凭据；未命中／不支持时为 null |
| status | FOUND／AMBIGUOUS／NOT_FOUND／UNSUPPORTED_QUERY，沿用 Provider 含义 |
| queryKey、dataset | 规范查询键及本次固定文字 DatasetRef，不将音频版本混入文字版本 |
| resolvedLemmaKey | Provider 唯一有据归并时返回；歧义为 null |
| entry | FOUND 时选中的第一个区域；AMBIGUOUS／无结果时为 null，兼容总体接口中的单 entry 入口 |
| regions | 所有候选，保留 entryId、senseId、区域／组件身份、POS、IPA、标签、notes、顺序、来源及权利；不以第一项消除歧义 |
| source | 服务端重建的 canonical source，附 artifactHash、pipelineVersion、contextKind；不回传用户私有存储路径 |
| pronunciations | 默认 entry 的独立音频结果；未确定展示项时为 null；每个 region 另附自身 pronunciations，供歧义／区域切换，无需客户端伪造 lemma |
| audioError | 音频数据库／存储依赖失败时为受控错误码，正常时为 null；不能伪装为 missing |
| favoriteState | 固定 null，表示 M06 未接入，不能写成 unsaved 冒充真实查询 |

这是对系统第 15 章概略接口的 MVP 细化：保留 entry 和 source，增加显式 status／regions 以承载 M02 的真实一对多结果。前端校验 DTO，不能把坏 JSON 或未知状态当作空结果。entry 和 regions 的数据可共享逻辑投影，避免不一致。

### 5.2 文字与音频装配

直接复用 DictionaryProvider.lookup(surface,posHint)，不改 col-normalize-v1，不增加删 s／ing 的规则，不强行归并 saw 等不同 lemma。Provider 固定本次文字 DatasetRef，批量读义项与既有缓存保持原实现；用户来源和凭据不能写入全局词典缓存。

对实际展示的每个不同 headword 调用 AudioCatalog.find(headword,normalizationVersion)，同词头在一次装配中复用结果。音频失败不改变文字 FOUND／AMBIGUOUS；仅捕获明确的音频依赖错误，编程错误不得全部吞掉。多区域响应需要同一音频数据集快照：实施时给 AudioCatalog 增加内部批量／固定 DatasetRef 入口，保持原单词入口兼容，不能循环读取活动指针后混装多个版本。

pronunciations 复用已有 status、word、source、audioDatasetId、audioDatasetVersion、items[{audioId,accent,mime,durationMs}]。AMBIGUOUS 音频结果仍可包含另一口音的唯一 items；只展示这些可用录音，不选择被过滤的歧义录音。notConfigured 与 missing 区分；依赖错误用 audioError 单列。未命中文字不额外制造一个有释义的结果。

本轮不引入 compromise。POS 推断可在后续有实际需求时单独加入；可选 POS 只稳定调整义项顺序，不能删除其他候选。这是 MVP 实施范围收敛，不宣称完成原 M05-03 的前端 NLP 全部能力。

### 5.3 lookupId 的最小实现与后续收藏衔接

使用随机 UUID 的进程内短期凭据：TTL 10 分钟，绑定 userId、规范 source、固定 dataset、候选 entry／sense ID 和唯一性状态；上限 1000 条且估算 16MiB，单条超过 256KiB 不保存并返回 503 LOOKUP_CAPACITY_EXCEEDED。容量不足先逐出过期及最旧记录，不能无限保留。仅存候选身份和必要来源，不重复缓存全部释义；访问需并发保护。

凭据不写 Session，不建立表，不做浏览器持久化。TTL 到期、容量逐出或进程重启后返回 410 LOOKUP_EXPIRED；其他用户读取返回 404。此校验目前由内部服务提供，不新增公开取凭据接口；M06 接入时再用于保存，并重新验证当前账号、书籍／产物与权利条件。歧义凭据保留全部候选，没有明确选择前不形成收藏主体。M06 如需跨重启能力，再独立设计持久化。

### 5.4 状态与错误

| HTTP／代码 | 前端行为 |
| --- | --- |
| 200 NOT_FOUND／UNSUPPORTED_QUERY | 显示未收录／不支持此查询，保留原句，不改成网络失败 |
| 400 请求类型／枚举／UUID 错误 | 显示请求无效，不自动重试 |
| 401／403 CSRF 错误 | 复用现有认证／CSRF 处理；不得无条件重放 POST |
| 404 BOOK_NOT_FOUND | 包括跨用户和不存在；不暴露资源存在性 |
| 409 BOOK_NOT_READY／ARTIFACT_REVOKED | 关闭当前查询并提示重新打开书籍；书籍不可读时按 reader 既有错误处理 |
| 422 SOURCE_INVALID／TEXT_INDEX_MISMATCH／SOURCE_TOO_LONG | 说明定位不可用；阅读继续，不保存错误来源 |
| 503 DICTIONARY_NOT_CONFIGURED／DICTIONARY_UNAVAILABLE／DATASET_NOT_READY／STORAGE_UNAVAILABLE | 可明确重试，不能当未命中 |
| 503 LOOKUP_CAPACITY_EXCEEDED | 提示稍后重试，不返回无法核验的成功凭据 |

错误代码是本次拟定契约；具体既有服务错误统一映射，不泄露堆栈。音频单独降级，不能把整段文字错误当音频问题隐藏。

## 6. 卡片、坐标与音频生命周期

卡片位于父页，非模态、无全屏遮罩。默认宽 390px，最大 viewportWidth−32px、最大高 75vh，边距至少 16px，内容内部滚动；依次尝试右、左、上／下。优先扩展现有 position.ts，支持动态测量及 iframe 坐标换算；若确有不足再记录原因并引入锁定版本的定位库，不把“必须安装 Floating UI”当交付条件。

主释义加两条其他释义，超过部分折叠；保留 Provider 稳定顺序。同一 lemma 的多个区域／子词候选可切换；不同 lemma 先展示候选选择，不能标识为自动识别完成。缺 IPA 保持缺失，不借邻词或音频口音补写。标签与 notes 独立显示，无词典例句；原句中按 wordStart／wordEnd 高亮实际那一处，不替换全部同词文本。渲染为安全 React 文本，不注入词典 HTML。

请求生命周期由 book generation＋selectionId＋AbortController 控制。换词先清空旧释义／音频状态；关闭、翻页、切章、目录／设置打开、重排、切书和退出时 abort、失效 selectionId、移除高亮并停止播放。迟到响应、play Promise 和媒体事件全部检查身份；取消前端消费不等于服务端已取消。

共享 PronunciationPlayer 维护一个 Audio 实例，preload='none'；只有点击才设置同源鉴权 src 并调用 play，不自动下载，不用 speechSynthesis／TTS。状态为 idle／loading／playing／ended／error／unavailable。点击同一个正在加载／播放的录音执行停止，再点击从头播；换口音先停止旧录音。清理统一 pause、清空 src、load、移除监听器并增加播放 generation。

按钮明确标“播放 book 英音／美音”等实际词头和口音；原文 ran 展示 run 时不能无提示播放原型。播放失败允许显式重试，不自动换口音。原生 Audio 的媒体错误无法可靠给出 HTTP 状态时显示通用播放失败，不能推断已退出；认证状态仍沿用现有 AuthProvider。

键盘最低能力：正文块提供可发现的查询入口，左右在块内移动逻辑词，Enter 查询；不为每词插节点／增加 Tab。此模式消费左右键，其他情况保留翻页。Escape 关闭、焦点回原块或阅读容器，卡片按钮可 Tab，焦点在按钮时不触发后台翻页。辅助文本使用 aria-live 礼貌提示状态；屏幕阅读器全矩阵后置。

## 8. MVP 必要验证与后置范围

只增加能验证关键行为的正式测试，避免对 UI 文案和每个分支机械补测试。现有用例不删除，不把历史通过数量当作本轮结果。

| 编号 | 必要验证 | 方式与通过依据 |
| --- | --- | --- |
| Q01 | 普通词、跨 inline、重复词、撇号／连字符、行尾空白 | 合成正文＋一次浏览器；实际点击范围与 surface 一致 |
| Q02 | UTF-16、表情／非 BMP、原句边界、伪造文本 | 前后端少量黄金夹具；正确输入通过，切代理项／跨句／坏摘要拒绝 |
| Q03 | 真实 COL 命中、缺词、歧义、子词身份 | Provider 适配测试及开发库实际查询；状态和 lemma 符合现有数据，不要求缺词变命中 |
| Q04 | 跨用户、匿名、缺 CSRF | readict_test 最小真实 HTTP／数据库用例；分别 404／401／403，不允许以 mock 替代归属验证 |
| Q05 | 快速换词、关闭／翻页后迟到响应 | 可控延迟测试；旧结果和音频不回填 |
| Q06 | 真实英／美音、缺失及部分口音歧义 | 实际可用词至少一个英美音组播放；缺失不出现假按钮，另一口音可用性不受歧义连带影响 |
| Q07 | 音频停止与认证 | 换词／关卡停止；退出后访问既有音频仍为 401；复用接口已有保护，不重跑完整 Range 矩阵 |
| Q08 | 卡片边缘、长内容、390px、Escape／焦点 | 当前可用桌面浏览器及 390px 冒烟；不越视口、不挤正文、控件可达 |
| Q09 | 回归与构建 | 前端 lint、统一测试入口、build；后端受影响单测和查词相关 MySQL IT，记录准确命令及实际执行范围 |

开发时先将新增单元用例纳入现有 `npm test`；前端执行 `npm run lint`、`npm test`、`npm run build`。后端先运行受影响的普通测试，MySQL 用 `mvn -Pmysql-it -Dit.test=DictionaryLookupIT verify`（新增此类后可用）或按实际类名选择；遵循项目配置的测试库保护，执行前核对 profile 与 URL。按项目现有打包配置构建 Web／dictionary-tool，防止新增 Web 组件污染离线入口；本轮不运行转换或导入命令。

不以运行完整 `mvn -Pmysql-it verify` 作为本轮前置条件；如复用／共享代码变动使已有功能存在实际回归风险，再针对扩展。构建／自动媒体事件不等于人耳试听或完整浏览器验收。

明确后置：第二次全量音频转换、全库质检、固定 50 词全量重跑、性能压测、多浏览器全尺寸、完整故障注入、屏幕阅读器矩阵、真实服务供应商接入。已有记录与遗留缺陷原样保留。

## 9. 运行、归档与交付

使用现有本机启动说明与受限本地配置；开发沿用 readict_dev 已启用数据集，集成测试仅使用 readict_test。首次实施记录实际文字／音频活动版本，不写死版本号；不得以缺词或缺音为由重新激活其他集合。真实个人 EPUB 不入库提交，记录脱敏书籍摘要及实际运行结果即可。
