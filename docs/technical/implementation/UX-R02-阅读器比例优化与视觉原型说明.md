# UX-R02 阅读器比例优化与视觉原型说明

日期：2026-11-25。状态：三张独立视觉方案已交付，等待用户选择；未开始交互原型或正式前端实现。

## 目标与边界

根据用户当前截图，改善纸面占比过大、外部留白不足、内部侧边空白过多和分页控件抢眼的问题。在暖色、英文衬线正文与深绿点缀的现有方向内探索，不新增翻译入口。此任务独立于 UX-R01 与 M04，不改写其完成条件。

只提交设计说明、参考截图与生成视觉稿；不修改 readict-app、既有交互原型、数据库、阅读偏好或进度。视觉稿中的页码为设计内容，不是实际 EPUB 分页结果。

## 依据与工具

用户提供的当前截图为本轮直接依据。使用本机 Edge 与 Playwright，在独立检查进程添加 `--no-proxy-server` 后成功打开[微信读书公开阅读页](https://weread.qq.com/web/reader/7c632ef05a49197c62b53f0)，在 1920×1080 视口浏览公开章节；未改系统代理，未登录、购买或绕过内容访问限制。

使用 Product Design ideate、内置 ImageGen 和 UI/UX Pro Max。后者的检索结果含不适用于阅读器的营销表单建议，未采用；仅参考间距、对比度、焦点和点击区域原则。每次生成均实际附带两张参考图片；完整提示词保存在本轮归档中。

## 构图目标

三张均按 1920×1080 目标构图：Georgia 约24px、1.8行高；同一书名、章节及英文片段；工具栏移至纸面外侧，分页两端均为轻描边；视觉按钮目标约75×32px，未来实际点击区域至少44px。保持状态提示预留区域，不为装饰新增产品能力。

| 显示顺序 | 方向 | 目标纸面／正文宽度 | 差异 |
| --- | --- | --- | --- |
| 1 | 暖纸平衡 | 1160／880px | 居中标题、圆形独立工具按钮、轻纸面阴影 |
| 2 | 紧凑书页 | 1080／840px | 更窄纸面、独立线性工具图标、更克制的边界 |
| 3 | 轻盈编辑 | 1200／920px | 左对齐标题、外置窄工具条、页码上方小菱形与短线 |

以上为设计目标，不是生成图的实测 CSS。生成工具输出三张均为1672×941，未拉伸或二次修改。标题、字距及宽度由图像模型近似呈现，不能作为精确字号、行高或像素规范；选定后需用真实浏览器重新校准。特别是第一张纸面仍比1160px目标更宽，第二张导航未完全与纸面左边对齐，第三张标题与正文左缘存在偏差，见归档复核。
