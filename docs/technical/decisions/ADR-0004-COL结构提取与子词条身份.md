# ADR-0004：COL结构提取与子词条身份

日期：2026-11-21。状态：采纳（用户批准M02提取器修复与质量复验计划）。

## 背景

双解析器读取一致。r2主要遗漏无句号双语边界、子词条、引用和标签。源位置加区域不足以定位嵌入子词条；提前清理href会丢失关系证据。现有成功数不等于语义或字段完整。

## 决定

先保留惰性AST、原始属性、文本顺序及UTF-16字符位置，再生成无脚本、资源和例句的安全文字。COL分段以括号／引号成组词法单元及完整英文前缀、局部中文结构为依据；不按首汉字截断。边界不明确保持FAIL，一源原子隔离。

显式子词条结构组有独立componentOrder；主组件0。同一major中的延续段归同组，跨major不按同名合并。身份元组entry-v2加入componentOrder，包契约升级readict-col-bundle-2；本轮不实现正式包。子词条无自身IPA保持空，不继承主词lemma。parentEntryKey仅为来源指针，不是归并关系。

用法标签和引用独立保存；DERIVATION_NOTE没有虚构中文义项。原始entry://目标优先、一次解码、句点不剥除；显示冲突保留ERROR。关系保留重复key、一对多和最多8跳。源缺陷候选不自动应用。

源词头分类独立于查询规范，col-normalize-v1不改。词缀、缩写符号和范围外短语有明确诊断，不当成普通词。

## 后果及验收

旧候选身份与新身份不兼容，必须重新生成；不覆盖旧r2证据。诊断schema升级为2，始终不可发布。未来Java／V5／正式包须同步字段契约后实施。本轮只做Node修复和复验，不迁移或接入HTTP。

用自建夹具测试结构、边界、安全、关系和身份；新90条保留集在候选冻结后评价；两次全源诊断比对摘要。技术未过、源缺陷未审批均如实登记；不靠失败数减少宣布完整M02通过。
