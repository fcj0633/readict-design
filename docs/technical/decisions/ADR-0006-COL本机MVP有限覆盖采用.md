# ADR-0006：当前 COL 的 LOCAL_MVP 有限覆盖采用

状态：已采纳；日期：2026-11-22。依据：用户确认沿用当前词典、不补齐，并批准《M02 当前 COL 词典 MVP 完成计划》。本决策补充 ADR-0004，不替代其子词条身份和证据保留规则，不影响独立 A02 发音任务。

## 决策

1. 完整扫描当前 COL，保留 ENTRY／ALIAS／SKIP／FAIL 的源级处置。必要区域有错误仍整源隔离；不从 FAIL 的局部成功区域发布数据，不补字、不在线补词、不采用人工修正表。
2. see also／compare 只有在记录已有独立释义且引用非根关系时才是附加关系。附加目标不可用或显示冲突只记 WARNING，不输出可用链接；跳转、其他身份关系、未知引用维持严格检查。规则升级 col-extract-r4。
3. 当前可安全解释的内容作为 LOCAL_MVP 使用范围。包内数据保持摘要、身份、计数、引用和字段约束；包外隔离记录有逐项原因，不要求全部源缺陷清零。此采用策略不等于修正源文或批准完整分发。
4. readict-col-bundle-2 增加 usageProfile=LOCAL_MVP、adoptionPolicy=col-local-mvp-v1、quality.localMvpEligible。quality.releaseEligible=false 保留完整质量门槛未通过事实；显式 --allow-local-mvp 才可校验、导入及激活。diagnosticOnly=true 永远不可导入。语义抽查验收保存在包外报告，不能把机器完整性校验称为人工质量审核。
5. entry-v2、sense-v1 与 col-normalize-v1 不变。源 pattern 中完整、括号包围、逗号分隔的词形列表可为所属主组件提供 INFLECTION 映射；不按列表顺序猜测语法类别，不继承给子组件。没有列表／说明证据的索引差异不生成映射。AM／also 元信息仍保留，不自动变成已审核修正。
6. 五表内保留完整词条／义项／映射 JSON 元数据及必要索引字段；notes、references、labels 和来源不能被导入丢弃。派生说明不生成假 sense。
7. READY 表示声明范围内的数据导入完整，激活仍独立执行并比较活动版本。测试库验收后允许向本机开发库迁移、导入并显式激活；不清理业务数据。实施中发现开发库仅V1，用户已明确批准按原样补执行既有V2～V4后继续V5，记录于本次验收。
8. 数据权利 UNVERIFIED、快照和分发 false；音频 null。M02 不增加 HTTP／前端／收藏，不声称生产或完整词典质量验收。

## 验收与后续

必须完成两次全量包确定性、Node／Java 独立校验、固定50词真实查询、恢复记录及其余记录各100条执行代理核对、真实 MySQL 幂等／事务／租约／切换／缓存与回归测试。结果见 [M02 记录入口](../../../validation/implementation/m02/README.md)。未通过项照实保留，不能仅凭计数下降标完成。

查询覆盖及源文质量的进一步优化留给 MVP 实际使用后评估，既有缺字、空正文、未知边界仍保留清单。需要提高完整质量门槛、修正原文或改变查询语法时另行确定。
