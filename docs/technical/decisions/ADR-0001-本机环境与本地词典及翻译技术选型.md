# ADR-0001：本机环境与本地词典及翻译技术选型

状态：已采纳（方案方向），实现和验证尚未完成。  
日期：2026-11-19。  
批准依据：用户本聊天选择本地 COL／腾讯云 TMT，随后明确要求本机 MySQL 开发验收及实施修订计划。  
关联：[CR-0002](../../requirements/changes/CR-0002-密码规则与本地词典及音频阶段安排.md)、[系统设计](../architecture/Readict-V1.1-系统技术设计.md)、[模块计划](../implementation/Readict-V1.1-模块化开发计划.md)。

## 背景与现有证据

本机 Java 21、Maven、Node 和 MySQL80 已有，Docker 引擎当前不可连接。正式 readict-app 无业务工程；现有 UI 是 Mock，独立 EPUB 实验在 Chromium 有有限通过证据，WebKit／Firefox 仍有失败／未完成面。安装的软件和本地缓存不等于新应用已构建或数据库已连接。

COL 快速抽查可读，含英汉文字和 Unicode 音标，义项／例句有 HTML 标识；251 条分散读取未失败，但不是全量语义质量或授权审查。当前 MDD 的两个资源是 result-min.css 和 yd_col.js，不含已发现录音。临时抽查解析器为 js-mdict 7.0.0，不代表后续选用版本已通过。

## 采纳决定及理由

| 决定 | 原因与边界 |
|---|---|
| Java 21＋Spring Boot 4.1 稳定系列＋MVC／JDBC／Security／JDBC Session，单体按业务包组织 | 配合本机环境与用户 Java 技术栈；不为当前规模引入微服务、中间件或无必要 ORM |
| 开发、集成测试、阶段验收全部使用本机 MySQL80／8.0.44 | 按用户明确决定，避免升级和多实例成本；分 readict_dev／readict_test 和最小权限，保护其他数据库 |
| 不把 Docker／Testcontainers 设为当前前置 | 当前引擎不可用，真实本机 MySQL 已可作为验证目标；未来容器化另评估 |
| 本地 COL 为首版数据源，Node 离线转换，Java 查结构数据 | 复用实际文件与已证明的可读性；不在点击时解析大文件，不增加常驻 Node 服务，不把 MDX 发给浏览器 |
| 优先验证 js-mdict 6.0.6 作为离线解析工具 | 该版本许可 MIT，仍需验证兼容、安全和完整性；不把 7.0.0 的抽查证据转移到该版本 |
| 腾讯云 TMT 官方 Java SDK 经 Provider 接口 | 用户选定，凭据／限制集中管理；只用户主动发送当前句，不默认购买／开通，不自动回退 MyMemory |
| 音频暂不决定具体实现，保留可空 audioId 和不可用提示 | 用户后续提供文件再分析；设备朗读不是录音的默认替代，其他文字模块可继续 |

密码规则属于 CR-0002 的需求决定：不少于 8 位且数字＋英文字母，允许额外符号，不再要求大小写；不降低原有哈希、会话或用户隔离设计。

## 替代方案与取舍

- 原设计“开发本机、验收另设新版本 MySQL”不再作为当前约束；将来生产版本与部署另定，不能外推本机结果。
- 直接在 Java 中引入未验证 MDX 库可减少转换工具，但解析兼容与许可未证实；首版选择离线导入，将格式复杂度隔离于查询路径。
- 常驻 Node MDX 服务增加部署／接口／生命周期，当前不采用。线上 Java 只依赖结构化数据与数据集版本。
- 本地＋在线词典双源并行增加范围，首版只实现本地。数据授权或质量无法满足时另行选源，而非伪造内容。
- MyMemory 仅为历史联通性参考，不作为正式翻译或自动故障切换；TMT 没配置时明确不可用。

## 风险、采用门槛与后续验证

1. M00：本机真实账号连接、驱动／Flyway／Session 和事务；测试只可清理 readict_test。服务启动不证明此项通过。
2. M02：解析器版本、50 代表词、词形一对多、中文提取、数据对账、幂等与活动版本切换；中文混排和缺字不能静默忽略。数据使用权利在公开分发前核实。
3. M03／M04：Java 安全处理、确定性索引与浏览器 DOM／CFI；epub.js 风险和兼容性仍按原设计门槛处置。
4. M07：TMT 配置、真实调用、限额、质量、隐私和译文保存条件；无凭据不标通过。
5. M01：PRD 密码恢复仍须实现，所有权验证服务待定；不能以未验证登录标识重置密码。
6. A01：音频文件到位后核对格式、编码、索引、词条／口音和播放，再修订契约；此前状态为待材料，不宣称音频验收完成。
