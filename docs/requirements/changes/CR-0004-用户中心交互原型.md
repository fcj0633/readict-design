# CR-0004：用户中心交互原型

日期：2026-11-27。任务编号：UX-U01。

范围来自本次用户明确要求实施的《Readict 用户中心 UI 原型设计》计划。范围已授权实施，视觉方案尚待用户评审；不视为正式产品验收或昵称字段已获采纳。

在 `prototypes/reader-ui` 内复用 React、Lucide、Base UI 对话框，新增独立 `user-center.html#/user-center/*` 入口。现有入口与记录保留。独立入口用于避免修改已有未提交的 Quiet Library 书架代码；Vite 同时构建两个入口。

- 头像菜单、个人账户、编辑昵称与修改密码对话框。
- 个性化设置仅含阅读设置、词典与发音；不提供通用设置或应用外观页。
- 阅读字体、字号、行距、660/720 比例宽度及三种阅读纸面的即时预览。
- 登录、注册、找回、重置与退出演示，固定 +86；密码沿用 8–128 字符、英文字母与数字、最多 512 UTF-8 字节的约束。
- 独立评审工具覆盖联系方式、验证状态、保存失败、版本冲突与退出失败。

仅昵称与偏好写入 `readict-user-center-prototype-v1`。不访问正式会话，不保存密码、验证码、恢复凭据或联系方式。昵称是待确认新增设计。所有验证、认证与同步均为演示；真实邮箱和短信通道未验证，不声称已发送。词典页依据当前 COL/音频源码及 M05 最新本地验收描述能力，缺少具体单词或口音录音仍可能不能播放；本页不调用真实词典或音频。

书架预览使用独立复制的本地封面资产，来源沿用现有 Standard Ebooks 素材清单：`public/user-center/covers/sources.json`。这些是示例资料，不代表真实导入、阅读进度或账号数据；复制到专用目录避免依赖或提交其他尚未完成任务的封面文件。

执行与浏览器验收记录：[UX-U01 验证记录](../../../validation/ui/2026-11-27/user-center/README.md)。正式 AuthProvider、PreferenceSaver、Session、CSRF、数据库及后端均未改动。
