# 需求变更登记

本目录管理基线形成后的需求变化。使用 [变更模板](../../../templates/requirement-change.md)，文件格式为 `CR-0001-主题.md`。编号递增，不复用已废弃编号。

状态：草案 → 待确认 → 已批准 / 已拒绝 / 已撤回；批准后实施进度可记“实施中、已验证”。状态变更必须有依据，不自动把历史讨论转换成已批准变更。
