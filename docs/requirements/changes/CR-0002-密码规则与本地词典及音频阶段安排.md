# CR-0002：密码规则与本地词典及音频阶段安排

状态：已批准；文档已修订，正式功能未开始。  
日期：2026-11-19。影响版本：PRD V1.1 的当日修订，不新设产品大版本。

## 确认依据与原因

用户在本聊天明确选择“本地 COL 优先”和“腾讯云 TMT”，随后要求开发验收都以本机 MySQL、密码改为不少于八位数字＋字母、音频先说明并待后续文件分析，并明确要求实施本修订方案。这是需求与阶段安排的直接确认，不以原型或实验建议代替批准。

## 需求调整

1. 密码不少于 8 位，至少含一个 ASCII 数字和一个英文字母；不要求同时含大写、小写，不强制特殊符号但允许额外符号。注册／改密／重置使用相同规则，登录仍验证已有哈希。旧规则由 Git 历史保存。
2. 首版标准英汉数据优先使用本地 COL，经版本化离线转换由 Java 查询；保留词典适配接口，不同时实施在线词典。词典数据实际使用授权仍需核实，不因用户选定数据源就视为第三方授权已取得。
3. 音频需求保留；当前已读 MDD 只含 CSS／JS，没有发现音频。等待后续文件分析，不预定格式／映射／口音／播放方案，不自动以设备朗读代替录音。
4. 本轮先验收文字释义、音标、词形及阅读／翻译／收藏闭环，音频不阻塞其他模块；音频未验证时不可宣称 V1.1 全量需求完成。

相关技术约束：开发／测试／阶段验收统一本机 MySQL80 8.0.44，同实例独立库；翻译目标为 TMT。这些属于技术安排，决定和风险见 ADR-0001。

## 范围核对与影响

- PRD 的说明、密码章节、错误提示和验收统一更新，当前基线仍为 V1.1。
- 更正技术稿将“密码找回不在 PRD”写错的事实：PRD 第 11.1 节确有恢复要求，纳入 M01；验证服务和具体所有权证明仍待决定，不用不安全流程补齐。
- 不新增复习、AI 消歧、短语查询或 PDF，不修改原型／实验历史结果。
- 尚无正式用户表／认证实现，不需要迁移已有密码；哈希、随机盐、限流与会话失效设计保留。未来有历史有效账号时登录不得按新复杂度拒绝其已有密码。

## 验收

文档规则：abc12345、ABC12345、Abc12345、abc1234! 通过；abcdefgh、12345678、Abcdefgh、abc1234 不通过。这是待实现的功能用例，本次不执行正式认证代码。

文档应一致引用本机开发／测试库和音频待材料状态；新词典接口、快照与任务关联数据集版本；M00～M09 状态为未开始，不把文档修订当功能通过。账号恢复未完成不得标账号全需求完成。
