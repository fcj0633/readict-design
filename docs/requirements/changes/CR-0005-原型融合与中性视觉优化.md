# CR-0005：原型融合与中性视觉优化

日期：2026-11-27。独立任务：UX-U02，衔接 UX-U01 / CR-0004。

用户已明确要求实施《Readict 原型融合与视觉优化：清爽、现代的私人书架》。本记录确认实施范围，最终视觉仍待用户评审，不追认旧设计已通过审核。

- 主入口统一为 `index.html#/books`，融合原有书架、收藏与用户中心；旧 `user-center.html` 地址保留同页映射跳转。
- 采用中性浅灰、白色、青绿及系统无衬线界面字体；复用实际前端“书形 r + Readict”品牌识别，增加轻立体封面承托、书脊和页边细节。
- 书架、收藏、账户、设置、认证页面共用导航与头像菜单。阅读器仅同步品牌及必要导航，保留正文、分页与词典卡布局。
- 用户中心偏好存在时优先用于设置页，否则读取原阅读偏好。加载不回写旧偏好；主动保存成功、或明确解决冲突并保存后，才同步五项阅读设置。昵称及口音保留专用存储，不迁移、重置书架或收藏数据。
- 主界面固定中性外观；阅读纸面和夜读仅影响阅读预览及阅读器。无通用外观分类。
- 正式认证、数据库及后端不变。昵称仍是待确认新增设计；认证、验证、同步及导入仍为演示。设置页明确区分正式前端 COL 音频与此原型的示例词典／浏览器语音，口音偏好不承诺真实录音播放。

为保留此前未提交的书架文件，新增 `src/integrated/Bookshelf.tsx` 承接现有行为和本次视觉，主路由使用此组件；原有未提交书架源码及样书改动不覆盖、不纳入本次提交。共用品牌、布局与偏好保存回调为原型内部接口，无后端 API 变更。
