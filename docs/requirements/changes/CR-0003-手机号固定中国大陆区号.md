# CR-0003：手机号固定中国大陆区号

状态：已批准，固定 +86 已实施并验证。日期：2026-11-20。
确认依据：用户明确要求手机号注册默认 +86，暂不支持其他地区，并确认兼容本地号码与 +86 完整号码；用户已授权实施完整 M01 计划。

## 原行为与目标行为

旧技术方案要求显式国家区号且不默认国家。当前版本限定为中国大陆 +86，不提供地区选项。

手机号仅支持中国大陆固定 +86，不提供其他国家／地区选项。接受 11 位本地号码或 +86 完整号码；trim 首尾空白后移除一次可选 +86，以 ASCII 正则 1[3-9][0-9]{9} 校验，统一保存 +86 加本地号码。拒绝其他区号、0086、重复前缀、内部空格／连字符和全角数字。注册、登录、恢复和限流共用此规范；格式有效不代表真实归属已验证。

## 影响及验收

PRD、系统技术设计、M01 执行指导、流程图解和模块计划同步；接口字段与 phone_e164 存储不变，不新增地区参数。两种输入的注册唯一键、登录、找回和限流一致；其他区号在直接 API 调用中也拒绝。真实号码归属仍须真实通道验收，模拟不能置真实 verified。
