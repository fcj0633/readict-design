## 0. 文档使用约定与结论分级

- **[B] 现有基线**：已经在 V1.1 PRD 确认的业务边界；本草案无权改变。

- **[P] 提议需求**：依据研究提出的可行设计，**尚未获得逐项批准**。

状态由具体条目标识；**不能因为出现在本 PRD 就自动视为已批准需求**。实验性建议与固定数值尤其不能直接进入实现。

## 1. 产品背景与目标

### 1.1 当前已实现/已规划的前置产品链路

[B] 用户在 Readict 中阅读自己导入的 EPUB，点击词汇查看标准词典解释和原句。只有**主动收藏**才会将单词及其原文语境持久保存。[V1.1 PRD](PRD-v1.1.md) 约定：
- 同一用户、同一 **lemma** 仅有一个单词收藏主体，不按词性或义项拆分。
- 新遇到的原文句子关联到已有收藏主体，保存原文、词形、书籍／章节和位置等快照。
- 首次收藏的主要词性／释义为快照，不自动被后续不同词义覆盖。
- 删除 EPUB 后已收藏单词及原文句子仍能查看。
- V1.1 **不含**复习页面、复习计划、复习日志、调度算法，也不预建完整复习表。

本草案从该收藏体系向后扩展学习，不把“查询过”视为“要复习”，不回头更改 V1.1 已有收藏入口与唯一性语义。

### 1.2 目标用户与任务

[U] 面向已有一定英语阅读基础、通过英文原版书持续积累词汇的人。主要任务是**先阅读、按需收藏，之后在独立模块完成系统化单词学习与长期复习**。

核心 Job：**当我在阅读中收藏了值得掌握的词，我希望之后能够通过清楚、有效、负担可控的练习记住它在所学语境中的含义，并逐渐在新的文章中理解它，而无需强制进行英语写作或拼写训练。**

### 1.3 产品目标与非目标

- **[U] 首要学习目标：接受性词义识别**——看见英文词（或被明确限定的具体语境），能回忆或识别所学含义。
- **[U] 期望阅读结果：语境理解**——能够理解用户收藏的不同用法；新语境理解属于后续效果验证目标，不能用原句答题正确率直接代替。
- **[U] 独立学习场景**：阅读中不弹出强制练习，复习任务在独立入口进行。
- **[U] 产品风格**：以不背单词的流程化学习、记忆反馈、卡片展示、互动反馈和结算作为主要参考；保留 Readict 用户原句与多语境的特色。
- **[U] 不强制**中译英、拼写、造句及主动英文表达。
- **[P] 成功判据**：除是否完成复习外，还应通过延迟识别和陌生语境测验验证记忆收益；测试方案见§13。
- **非目标**：预设考试词书及覆盖率任务、排行榜与社交、阅读时自动复习、整章语法讲解、由生成式 AI 直接给出未经核验的评分标准、自动声称长期掌握。

### 1.4 研究依据与约束

阶段一验证了不背单词的题前作答、答案揭示、自评、反馈纠正、同轮再现、分层结算等可见行为，但**没有获得其内部阶段公式或长期调度算法**。Readlang 实测显示同形词可关联多个来源句，以及多种复习模式。

阶段二研究支持**主动提取、纠错反馈和分散学习作为原理方向**，但未证明固定关卡、具体重复次数、某种 SRS 算法或目标用户的最佳负担参数。详见上述研究链接。

## 3. 关键业务概念与边界

| 概念 | 本草案定义 | 特别说明 |
| --- | --- | --- |
| 收藏主体 | [B] 每用户、每 lemma 一份收藏 | 归并与去重规则保持 V1.1 不变 |
| 语境记录 | [B] 收藏主体关联的原文句子和来源快照 | 一词多句，删书保留快照 |
| 目标义项 | [P] 某词在一个或一组语境中要记忆的含义 | 不能仅由“相同原句”或“词性相同”保证义项一致 |
| 复习目标 | [P] 系统安排并评价的具体学习对象 | 可能是词条义项/语境组合；**独立于收藏主体** |
| 题目 | 一次对某个复习目标的提问 | 同一目标在一轮中可多次出现 |
| 复习会话 | 用户主动开始至结束/中断的一次活动 | 题次数、词数、目标数必须分清 |
| 本轮完成 | 当次安排的目标达到本轮完成条件 | **不等于永久掌握** |
| 到期 | 按未来计划应当被再次练习 | 逾期不等于自动遗忘 |

**[D-01] 最关键决策：一个收藏主体可对应几个复习目标？** 用户已确认“不同语境可分别练习”，但**尚未确认**每条原句都单独调度、按义项归组调度，还是词条级调度并轮换语境。三者可在数据组织上共存，业务效果并不等价；详细方案见配套决策表。

## 4. 用户场景与完整流程

### 场景 S1：阅读时收藏，之后独立学习

[B] 在阅读器中查词 → **主动点击收藏** → 保存 lemma 和当前原文句子。**[P]** 当未来复习模块启用后，收藏词有资格进入“待首次学习”候选池，但**收藏操作不触发题目、不强制立刻安排完整复习会话**。

用户之后打开独立模块 → 查看待学与到期复习概览 → 主动开始一组任务 → 完成/中断 → 返回阅读。来源书籍、章节可在复习详情中查看，但不要求临时跳回阅读器。

### 场景 S2：首次学习候选路径

**[P]** 首次进入某个尚未学过的目标时，先确认可供学习的可信义项与用户原句（不是未经核实的 AI 译文）→ 尝试独立回忆目标词义 → 显示正确内容与反馈 → 根据表现继续下一目标或安排本轮追加练习。

- 初次展示完整释义还是先进行“你已认识吗？”预检，属于 **[D-02]**。
- 固定多关还是动态多阶段属于 **[D-03]**；不得从不背单词历史账号观察推定其内部固定关数。
- [P] 对已经熟悉且回答正确的目标，允许减少本轮无意义重复，但仍应在未来安排间隔回访；需经实验验证。

### 场景 S3：到期复习候选路径

**[P]** 用户进入独立复习 → 展示英文词形或能明确限定目标义项的句子，**先不泄露中文答案** → 用户主动回忆 → 揭示答案与来源 → 提交记忆反馈 → 系统更新本轮状态及未来待复习安排 → 继续下一目标。

- 单纯词形在多义情况下可能含糊；必须通过语境、义项提示或卡片目标范围消除“唯一答案”歧义，**不得用第一次收藏的释义错误判罚其他有效含义**。
- [P] 如果用户完全忘记，应显示正确解释，不让错误认知未经纠正就进入下一轮。

### 场景 S4：同词多语境

[B] 同一个 lemma 仍一个收藏主体；[U] 不同语境可分别练习。以 charge 为例：“收取费用”与“提出指控”应能作为**不同含义的练习问题**，但不自动创建两个“收藏单词”。

**[P] 候选方式**：一个收藏主体 → 语境记录集合 → 经确认的学习目标 → 题目与复习历史。多个表达相同义项的原句可作为一个目标的不同上下文提示；不能因为新增十句而无条件生成十个长期到期目标。

**[D-01/D-05]** 目标归组与释义确认方式未定；若某语境的义项不可靠，不能将其默认解释当作唯一标准答案。应提示词义待检查，允许查看可信词典与用户原句，并以获确认的材料出正式评分题。

### 场景 S5：持续遗忘与学习结束

**[P]** 错误/忘记 → 正确答案与解释 → 在之后适当插入再次提取；但应有**单轮重复上限或可提前结束机制**，不能无限阻止整轮结束。结束时区分“当轮通过”“需要后续巩固”“尚未完成”。

## 5. 功能需求（候选版本）

下面 ID 是未来实现和验收的追踪编号；状态写为 [U]/[P]/[D]，**不是已批准 P0 需求**。

### 5.1 复习入口与任务组织

| ID | 状态 | 功能规则 |
| --- | --- | --- |
| RV-ENTRY-01 | [U] | 提供与阅读器分开的主动学习/复习入口，不在阅读时强制插入任务 |
| RV-ENTRY-02 | [B]/[P] | 只有已主动收藏的单词可成为学习来源；查词历史不得自动等同学习池 |
| RV-ENTRY-03 | [P] | 展示待首次学习、当前到期复习、已暂停/待加强等概念上可区分的数量 |
| RV-ENTRY-04 | [P] | 用户可主动开始、暂停、结束会话；中断时不能误算未完成项 |
| RV-ENTRY-05 | [D-08] | 每轮学习目标数量、每日上限、复习优先级、用户跳过策略待评审 |

### 5.2 新词与长期复习

| ID | 状态 | 功能规则 |
| --- | --- | --- |
| RV-LEARN-01 | [U]/[P] | 新词学习采用多阶段组织思想，区分首次理解与后续主动提取 |
| RV-LEARN-02 | [P] | 只有具备可信目标义项的卡片才能进入正式判定；材料不可靠时给出明确处理方式 |
| RV-LEARN-03 | [P] | 题目在回答/揭示前不显示目标中文答案，帮助区分主动回忆与回看 |
| RV-LEARN-04 | [D-03] | 固定阶段与动态阶段之间的选择、题型转换与通过阈值待定 |
| RV-REVIEW-01 | [U]/[P] | 独立复习既有学习目标；根据反馈组织当前练习和后续复习 |
| RV-REVIEW-02 | [P] | 回答失败后呈现正确且与语境一致的解释；不把忘记永久判为学不会 |
| RV-REVIEW-03 | [D-06] | 同轮再次出现的时机、次数、连续失败处理待定；默认不接受无限循环 |
| RV-REVIEW-04 | [P] | 本轮完成与长期掌握状态分开，未来复习到期不因某轮完成而永久消失 |

### 5.3 卡片内容与题型

**[P] 候选题面/答面分工：**

| 场景 | 题面内容 | 揭示之后 |
| --- | --- | --- |
| 首次理解 | 英文原型、词性、可信词义、用户原句和来源 | 可查看更多释义/用法；不将此直接计为主动回忆正确 |
| 单词意义提取 | 英文词形、必要时的最小化消歧提示；隐藏目标中文答案 | 目标含义、原句、来源、词典释义及辅助说明 |
| 语境义区分 | 含目标词的英文原句或另一个经校验的句子；不预显中文答案 | 当前语境的参考含义、差异解释和其他关联原句 |
| 错误纠正 | 当前词、用户作答或自评提示 | 正确词义和针对当前误解的解释 |

- [U] 不把拼写、中文找英文、造句设为必过任务。
- [P] 英→中选择题可作为初步识别/辅助，但避免从一次猜中推导无提示掌握；干扰项应可靠，错误后清楚解释。
- [P] 原句应可在反馈阶段完整查看，题前是否展示随任务目标而异；过多提示可能让用户靠原句记忆猜对。
- [P] 词典可靠性优先于自动生成的解释；若词典/翻译不可用，不能伪造可信评分答案。
- [D-04] 可选强化题、题型比例、音频自动播放、是否提供独立“先看词义”模式，留待原型评审。发音资源仍受既有真实音频可用性限制。

### 5.4 记忆反馈与纠错

| ID | 状态 | 功能规则 |
| --- | --- | --- |
| RV-FEEDBACK-01 | [P] | 候选三级评价为“认识／模糊／忘记了”，附明确简短解释 |
| RV-FEEDBACK-02 | [P] | 认识：揭示前能回忆目标义项；模糊：部分记得/依赖提示；忘记：未能回忆或理解错误——具体文案待验证 |
| RV-FEEDBACK-03 | [P] | 提供误判纠正入口（参考不背单词“记错了”），使被撤回的评价不能继续错误影响当前进度 |
| RV-FEEDBACK-04 | [D-07] | 自评提交时点、撤回有效范围、重新提交和长期间隔更新如何补偿待决策 |
| RV-FEEDBACK-05 | [P] | 记录评价时须保留题型、是否有提示、目标义项与评价原始语义，避免以后算法映射失真 |
| RV-FEEDBACK-06 | [D-09] | 三级评价如何映射到具体间隔算法待选型；不能机械规定“模糊=某种算法的 Hard” |

### 5.5 多语境、义项与来源管理

| ID | 状态 | 功能规则 |
| --- | --- | --- |
| RV-CONTEXT-01 | [B] | 一个 lemma 一个收藏主体，多条原句分别保存，不因复习生成重复收藏主体 |
| RV-CONTEXT-02 | [U]/[P] | 不同含义可分别练习；对同义的多个句子应避免无条件产生重复的待办 |
| RV-CONTEXT-03 | [P] | 每张判分卡必须有可明确解释的目标含义或允许的答案范围 |
| RV-CONTEXT-04 | [P] | 用户能够查看该练习与原书籍/章节、原文句子的对应关系 |
| RV-CONTEXT-05 | [B]/[P] | 删除 EPUB 后，已收藏的原句与来源快照仍可用于复习，不假设原书链接始终可用 |
| RV-CONTEXT-06 | [D-01/D-05] | 义项如何由词典、用户确认或其他策略归类；何时允许形成可调度的独立复习目标 |
| RV-CONTEXT-07 | [D-10] | 释义被纠正、新增或移除句子后，历史练习和计划如何处理 |

### 5.6 长期复习计划与学习负担

- **[P]** 系统应能确定学习目标何时再次到期，并向用户呈现清楚的计划状态；不要求首次推出完整算法参数调优界面。
- **[P]** 到期但用户没有打开产品，不应自动算作用户“忘记”；任务保留至后续处理，允许分批完成。
- **[P]** 同轮错误重复不能无限增长；用户可结束，未完成目标继续留待复习。
- **[P]** 学习计划不能因某单词拥有很多原句而无上限地膨胀；词义/语境粒度与调度策略必须共同评审。
- **[D-09]** 固定间隔、SM-2 类、FSRS 的选择、初始参数、目标保持率、冷启动与迁移策略在技术决策阶段确定。技术选型需满足业务规则，**本 PRD 不指定算法名称**。

### 5.7 会话、进度与结算

**[P] 主要页面**：独立学习首页（待学/到期）、卡片题面、答案与反馈、当轮小结、学习记录/词条详情。具体版式通过 UX 原型确认。

用户可理解的计数需分开：
- **收藏词数**：当前收藏主体个数。
- **学习目标数**：由已确认义项／语境组织形成的待学习对象个数。
- **题目次数**：实际提交的练习次数，允许一个目标多次出现。
- **本轮完成数**：按已确认完成条件完成的学习目标数。
- **到期目标数**：需要在后续时间安排的学习目标数。
- **待加强**：因持续失败未能在本轮通过的目标数（若采用这一状态）。

**[AC 草案]** 用户回答同一目标三次，不应被展示为新学三个不同单词；单轮完成提示不得写成“永久掌握”。

## 6. 状态与生命周期（产品概念，不是数据库枚举）

以**复习目标**为主要观察对象，而不是把状态直接刻在收藏主体上：

```text
收藏 lemma+关联原句
   └─ [有明确目标义项] → 待首次学习
           └─ 首次学习会话 → 当轮通过 / 待加强 / 未完成
                  └─ 进入间隔复习安排 → 到期 → 复习会话
                            └─ 按反馈调整未来到期
   └─ [义项不确定] → 待核实材料（不能当作具唯一正确答案的测验）
```

以上状态词用于需求沟通，仍需 **[D-01、D-03、D-09]** 才能变成产品状态机。

必须分别维护或可重建：
1. 收藏主体及原句是否仍存在；
2. 哪个义项／语境正在练习；
3. 当轮题目和评价提交情况；
4. 当前学习状态和未来安排。

## 7. 中断、异常与数据一致性

| 编号 | 场景 | 候选应对规则（[P]） |
| --- | --- | --- |
| EX-01 | 学习中返回首页/关闭页面 | 已成功提交的反馈和进度持久化；未确认提交的回答不得算成功 |
| EX-02 | 刷新/重进 | 保留已完成状态；是否恢复精确题面不是强制前提，但不可重复记账 |
| EX-03 | 反馈网络提交超时，用户重试 | 避免重复推进阶段、重复增加复习次数或重复更新到期 |
| EX-04 | 连续多次忘记 | 显示答案并允许退出或暂停；不陷入无限同轮循环 |
| EX-05 | 一段时间未复习 | 未完成任务保留；区分“到期”和“确实遗忘” |
| EX-06 | 多个语境含义冲突 | 不自动用首次收藏词义判错另一合法义项；需确认目标范围 |
| EX-07 | 词典词义/原句翻译缺失 | 仍可查看原句；无可信正确答案的题目不能被伪装成准确判分 |
| EX-08 | 用户删除 EPUB | 已收藏语境快照仍可用于复习；原书跳转可能不可用 |
| EX-09 | 用户取消收藏 | 遵循 V1.1 收藏主体删除语义；复习队列需移除/停用对应对象，历史保留或删除按 [D-10] 决定 |
| EX-10 | 同时两个设备操作同一复习目标 | 不产生不一致的重复推进；冲突处理与可见反馈需技术设计 |
| EX-11 | 修改释义或移动语境 | 确保旧反馈记录仍能解释当时针对的答案；历史纠正策略待定 |

## 8. 交互原则（非视觉稿）

- **分离主动回忆与答案揭示**：在需要提取时不提前展示中文参考答案。
- **逐步披露信息**：题面聚焦，答案页再显示相关释义、原文和必要助记，不堆砌所有义项。
- **反馈语义清晰**：明确“认识／模糊／忘记了”的区别，提供发现误判后的纠正机会。
- **有结束感但不制造强制压力**：一轮可完成，也可中断；进度和未来待办口径一致。
- **阅读来源可见**：例句应来自用户的原文快照；如使用校验后的新测试句，要与“用户原句”明确区别。
- **可选而非强制的强化训练**：不把拼写、反向中译英设为通过条件。
- **可访问性与输入**：所有核心操作应有清楚文字，不只依赖颜色；桌面端键盘操作、焦点顺序需由 UX 设计验收。

## 9. 业务优先级与验收原则

本节只定义**可验收的行为结构**，未决事项批准后补齐具体数值。

### 候选最小闭环的条件性验收（[AC]）

1. 登录用户只对**主动收藏**的词看到学习候选；未收藏的普通查词不加入待学队列。
2. 同一用户的同一 lemma 即使有多条原句，收藏主体仍只出现一次。
3. 学习入口独立；在阅读中不会因为收藏自动弹出强制题目。
4. 首次学习能完成“可信释义理解 → 回忆尝试 → 答案揭示 → 记忆评价”的闭环。
5. 已学目标能在未来安排复习，且一次当轮通过不会被解释成永久掌握。
6. “认识／模糊／忘记”能产生明确反馈；误触纠正不会导致重复完成统计。
7. 同一目标本轮多次出现时，词数、目标数与题次数的统计不会混淆。
8. 失败后能获得正确解释；连续失败可安全结束或保留后续计划，不无限循环。
9. 中断或提交重试后，不会丢失已成功提交的学习进度，也不会重复推进。
10. 书籍删除不导致已收藏语境丢失；取消收藏后的学习数据遵循批准的数据生命周期规则。
11. **多个不同义项必须有可区分的正确答案范围**，不得误用首次收藏含义判错后续语境。
12. 用户间收藏、语境、复习日志和任务计划必须隔离，不允许跨账号访问。

**阻塞**：第 4、6、8、10、11 条的完整自动验收依赖 [D-01～D-10] 具体方案确认。不能以这份草案直接创建未经批准的自动化验收门槛。

## 10. 数据与非功能需求边界

这里记录**业务需要的信息**，不指定表、索引或技术栈：

- 收藏主体、目标义项/语境参考、题型、题面/参考答案版本、用户原始反馈、评价提交与纠正记录、当前阶段、到期计划、会话进度等之间应能追溯。
- 已提交的评价应能够幂等更新或消除重复提交影响；纠错必须对当前状态产生可解释的修正。
- 正式题目所用释义必须能追溯到词典或明确的用户核验结果，不能以 AI 任意生成内容为唯一“正确答案”。
- 用户只可访问自己的复习进度和收藏材料；已保存原句和词义不能因外部网络故障自动丢失。
- 关键用户操作应在正常条件下及时反馈，具体性能阈值待产品/技术联评，**不沿用未经测试的假定数字**。
- 兼容 V1.1 的现有收藏关系；任何涉及 V1.1 收藏表结构或规则的提前改动，须另走变更评审流程。

## 13. 研究验证与上线效果评估（不构成产品现有数据表现）

**[P] 可用性验证**：邀请符合目标的英文原版书读者，执行“首次学习、忘记、纠错、同词多义、退出恢复”任务。观察能否理解反馈与计数、完成时间、额外操作及主观负担。探索性小样本不应当被当成统计上的显著效果证明。

**[P] 学习效果验证**：对比固定多阶段与动态多阶段候选流程；控制词汇基础、词义材料、练习时间和任务难度；在即时与延迟测试中加入**未出现过的新语境题目**，评估目标义项识别，而不是只看原句卡片正确率。研究方案及来源详见阶段二报告。

本草案不设无真实依据的日活、留存、成绩提升百分比或商业 KPI。
