# 需求基线

当前依据：[PRD V1.1（2026-11-19 修订）](prd/PRD-v1.1.md)。迁移时保持原文，本次按用户明确指令修订，修订前版本保留于 Git 历史；产品版本仍为 V1.1。

## 2026-11-19 已确认修订

- [CR-0002](changes/CR-0002-密码规则与本地词典及音频阶段安排.md)：密码不少于 8 位且至少一个数字和一个英文字母，不要求大小写同时出现，允许额外符号；注册／改密／重置一致。
- 首版本地 COL 优先，TMT 为翻译目标；开发／测试／阶段验收均为本机 MySQL80，独立开发库／测试库。
- 发音需求保留，音频等待后续文件分析，不阻塞文字模块；本轮不能声称真实录音已完成。
- PRD 已要求忘记密码和密码重置，验证服务尚待确定，完整账号验收包含恢复流程。

## 已确认边界

- 产品以英文原版 EPUB 阅读、查词和语境收藏为主。
- 第一版使用“收藏”，不做学习库、复习页面、复习计划或复习算法。
- 设计验证阶段使用 Mock UI 原型；独立阅读器技术实验不自动成为产品实现。
- UX 文档中出现的旧“学习库/复习”描述不覆盖 V1.1 和用户后续确认。

## 已确认 UX 修订

用户选择第一张视觉方向，并确认：底部“上一页/下一页”；不提供额外词典例句；主要释义之外默认再显示两条其他释义，超出折叠。原文语境作为独立区域保留。参见 [UX 设计规范](../ux/design-spec.md) 和 [修订稿](../ux/assets/concepts/reader-selected.png)。

UX 修订是既有确认登记；本次明确批准的新增变更单独登记 CR-0002。后续变更见 [登记表](changes/README.md)，按版本／修订记录保留历史；模板、未决讨论和实验建议不能替代当前基线。
