# 需求基线

当前依据：[PRD V1.1](prd/PRD-v1.1.md)。该文档从原根目录迁移，内容保持不变。

## 已确认边界

- 产品以英文原版 EPUB 阅读、查词和语境收藏为主。
- 第一版使用“收藏”，不做学习库、复习页面、复习计划或复习算法。
- 设计验证阶段使用 Mock UI 原型；独立阅读器技术实验不自动成为产品实现。
- UX 文档中出现的旧“学习库/复习”描述不覆盖 V1.1 和用户后续确认。

## 已确认 UX 修订

用户选择第一张视觉方向，并确认：底部“上一页/下一页”；不提供额外词典例句；主要释义之外默认再显示两条其他释义，超出折叠。原文语境作为独立区域保留。参见 [UX 设计规范](../ux/design-spec.md) 和 [修订稿](../ux/assets/concepts/reader-selected.png)。

上述是既有确认的范围登记，不新增虚构 CR 或批准记录。后续需求变更见 [登记表](changes/README.md)，按版本保存新 PRD；模板、未决讨论和实验建议均不能直接替代当前基线。
