# Readict 首阶段界面设计

设计依据：仓库中的 PRD V1.1、UI/UX 设计需求和阅读器界面调研。以用户选定的第一张 Quiet Folio 视觉稿为方向，采用随后修订的 [选定修订稿](assets/concepts/reader-selected.png) 为视觉依据。

## 已确定的设计规则

- 文学杂志式排版：暖白纸面、米灰背景、深灰正文、克制的深绿交互色；正文居中限宽，不做后台式布局。
- 英文正文 Georgia 默认 20px、行高 1.8，标准最大宽度 660px；字号、字体、行距、宽度和主题可修改。
- 单页分页。页码来自实际渲染，不沿用概念图里的虚构总页数。阅读位置以章节和字符偏移保存。
- 工具栏只有目录、收藏、阅读设置。目录和设置覆盖显示且互斥，不改变正文尺寸。
- 用户修订：底部为“上一页／下一页”；词典区不提供额外词典例句；默认主释义加两条其他释义，剩余折叠。
- 原文语境独立呈现，用于理解、主动翻译和收藏；默认不翻译。
- 词典是非模态浮层，以实际选词锚定，优先右侧、其次左侧，空间不足时调整上下位置；长内容内部滚动。
- 收藏按 lemma 合并；同词新句子追加，重复语境去重；取消收藏删除该词所有关联句子，删书保留收藏快照。

## 页面与组件

| 页面/区域 | 组件 | 责任 |
|---|---|---|
| 阅读器 | ReaderPage / Reader | 样书选择、真实重排分页、位置恢复、键盘操作 |
| 阅读设置/目录 | ContentsPanel / ReadingSettingsPanel | 互斥覆盖面板、偏好持久化 |
| 查词 | DictionaryPopover / ContextSentence | 浮层定位、词条、词义选择、原文、异步翻译、收藏 |
| 书架 | BookshelfPage / ImportDialog | 搜索、继续阅读、模拟导入、删除 |
| 收藏 | FavoritesPage / FavoriteDetail | 单词/句子视图、搜索、来源筛选、排序、原文返回 |
| 全局 | StoreProvider / Header / ConfirmDialog | 本地状态、安全回退、导航与确认 |

界面使用系统无衬线字体，英文阅读使用 Georgia / Palatino / Arial。深色主题独立定义纸面、文字、选词和按钮颜色。Lucide 图标采用目录、星标收藏及齿轮设置，与选定视觉方向统一。

## 状态与数据边界

Mock 服务集中在 `prototypes/reader-ui/src/lib/services.ts`，样书和词条在 `prototypes/reader-ui/src/data/mock.ts`。词典、翻译、收藏和导入均有清晰的状态反馈。请求可取消，旧结果不能覆盖新选择。

状态保存在 `readict-prototype-v1` 本地记录中；损坏时回退默认配置，不可写时保持会话可用。没有真实账号隔离、跨设备同步或后端服务。

后续依次接入真实 EPUB 引擎及 CFI、标准词典与词形/词性服务、翻译服务和账号持久化。复习功能不属于本阶段。

## 2026-11-23 阅读器 UI 优化

- 正式应用阅读页改为 60px 顶栏（返回、书名、当前章节）+ 独立纸面 + 右侧 Lucide 工具轨 + 纸内底栏；目录/设置改为覆盖式抽屉，不改变 iframe 尺寸。
- 纸面宽度 `clamp(920px, 76vw, 1100px)`，正文仍使用 660/720px 行宽；1920/1440/1366 三档桌面为当前验收基线。
- 保存状态收进底栏，失败时显示“未同步 · 重试”，不再使用顶部通栏错误条。
- M03 manifest 的 TOC 仍是扁平列表，目录层级由前端按 PART/BOOK/... 标签做展示层分组，不修改后端契约。
- 查词卡片当前仅为 `?preview=dictionary` 的开发视觉预览；真实 M05 查词与 M06 收藏仍未接入。
- 实测记录与截图：[阅读器 UI 优化记录](../../validation/ui/2026-11-23-reader-redesign/README.md)。
