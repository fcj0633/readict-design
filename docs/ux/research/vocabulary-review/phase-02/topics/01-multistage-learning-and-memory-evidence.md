# Readict 阶段二专题研究：多阶段词汇学习、记忆机制与语境复习

> **状态**：独立研究报告／候选方案，**未批准需求或技术架构**。研究日期：2026-11-23。
>
> **研究目的**：针对 Readict 已确定的“词义识别为主、独立复习、偏好不背单词式多阶段流程、同词多语境可分别练习、平衡学习收益与负担”的方向，评估真实竞品证据与学习科学，提出可验证的产品候选方案。
>
> **范围边界**：本报告不是不背单词内部算法审计；没有新做真实用户实验；论文研究对象和条件与 Readict 不完全相同。凡下文出现具体阶段数量、重复阈值、时间上限等，均是待验证候选参数，而非学术结论、竞品公式或既定 PRD。

## 1. 执行摘要

**建议继续研究“动态多阶段的接受性词义学习”**，而不是复制不背单词的题型顺序。其机制可以分为：先建立可信的词形—词义联系 → 无答案主动提取 → 出错后及时纠正 → 根据成功或失败决定是否在本轮追加练习 → 在之后的日子安排分散复习 → 适度加入不同语境测验。独立复习入口保留用户自主性；不强制中译英、拼写或造句。

可以相对有把握确定的**原理层结论**：
1. 主动提取和间隔练习是较强的长期保持研究方向；但“不背单词目前的具体多阶段规则最佳”**没有证据**。
2. 反馈、答案正确性和测试条件非常重要；单纯反复答题或始终显示答案不足以确保长期效果。
3. 原句适合初次理解和反馈说明，但在某些记忆测验中，原句信息过多会让用户靠线索猜词义；要区分“原句理解”与“独立提取”。
4. 间隔重复与同轮多题是不同时间尺度：后者不应无限叠加；不应把单轮通过等同长期掌握。
5. Readict 的“一个 lemma 一个收藏主体”与“多个语境可分别练习”可以共存，但训练目标／记忆状态的粒度需要独立决策。

### 证据综合判断

- **强支持（原理）**：主动提取、答案校正、间隔复习，比单纯重复查看更值得作为学习机制基础。
- **中等／条件性支持**：变化题型、练习材料语境、同轮多次正确、不同时间点再学习，需匹配具体测试目标和学习者。
- **暂缺直接证据**：不背单词哪一个关卡顺序最佳；本次三档自评能达到何种预测准确度；Readict 的最佳默认词数、最长会话时间、重试次数。

## 4. 关键设计问题：从论文结论到产品机制

### 4.1 为什么多阶段，而不是只翻卡一次？

从研究角度，多阶段的价值**不在“有几个关卡”**，而在区分两种学习行为：

1. **编码／理解**：先看单词、词义与来源句，建立可靠的初始联系。
2. **主动提取／纠正**：在看不到完整答案时尝试回忆；之后才揭示与纠正。
3. **再次成功提取**：在之后的间隔里重复，避免一次偶然答对就视为长期掌握。

不背单词实测符合上述结构的一部分，但它的准确内部规则不可见。因此，Readict 应借鉴**“多次有意义的提取机会”**而不是**“必须固定闯三关”**。

### 4.2 是否必须三次答对？

R03 对特定材料得出较具体的训练次数建议，但 R04 与 Anki 官方调度资料都提示时间间隔和负担问题；多次密集完成并不能替代跨日复习。故 **3 次不是 Readict 的科学默认常数**。

适合进一步测试：单轮一次无提示成功是否可以提前结束；连续失败后最多如何追加；跨日回访取代堆叠同轮题。

### 4.3 为什么先显示原句还是先隐藏原句？

不能统一规定“永远显示完整原句”。R05 表明过多线索可促进当下推断，却削弱某些条件下独立词形—词义联系的训练；R06 与 R07 则提示语境对词汇知识仍可能有益，尤其取决于测验和语境多样性。

**候选分工**：
- **首次学习与答案反馈**：显示原文句、书籍来源、核实后的当前释义。
- **目标是单独识别词义时**：先展示目标词（必要时提供最少量的词义消歧线索），用户主动回忆后展示答案。
- **目标是语境义区分时**：展示某个来源句或新句，要求区分意义；避免题面已经直接提供中文答案。
- **迁移检验时**：使用用户未见过、含义明确的新句，避免把熟悉原句记忆误判为泛化。

必须注意 polysemy：不能只展示 “charge” 再要求唯一的中文答案，而不说明测试的是“收费”还是“指控”。

### 4.4 为什么三级自评值得借鉴，但不能直接映射算法？

不背单词观察到“认识／模糊／忘记了”和“记错了”；此交互有清晰的心理语义，且用户纠正能够使组内进度回退。但这是**操作优点**，不是分档信号已被校准为真实记忆概率的证据。

建议研究阶段将反馈定义为：
- **认识**：看到题面后可在揭示前主动回忆出目标含义。
- **模糊**：有部分印象、犹豫或依赖线索；如完全忘记，则不得仅因“猜得接近”算成功。
- **忘记**：没有回忆出目标含义，或事后发现误解。

以上只是**待验证的用户提示语定义**。若采用 FSRS，不能不加转换地把“模糊＝Hard”——Anki 明确警告“忘记却选 Hard”会使预测间隔不合理。应保存原始反馈、题型、是否显示线索、正确性等，后续再建立可审计的评分映射。

### 4.5 答错后应追加提示还是直接揭示？

R08 的三项课堂实验表明，精细提示并不必然提高后续无提示回忆，且耗费额外时间；R09 认为多选误选后的纠正尤其重要。

候选规则：先短暂自主回忆；失败后及时给出清楚且可信的词义、与来源语境相符的用法；如果要重试，把它作为**新的提取机会**安排在后面的词之后（而非机械连续点同词），并限制会话增长。

反馈是否**立即**给还是**全批次之后**给，R10 没有发现控制测试间隔后普遍显著的优劣，因此“即时纠错”主要是可用性和降低错误学习风险的设计选择，须避免宣称它在所有学习条件下都显著优于延迟反馈。

### 4.6 混合旧词、同轮重试与跨日复习有何不同？

- **同轮重新出现**：目标是纠正失败、形成再次成功提取机会；过于密集会变成对刚看过答案的短时记忆。
- **跨日间隔复习**：目标是长期保持与避免遗忘；文献支持分散学习，但具体算法未由竞品实测揭示。
- **新旧词混合**：可能促进累积回访；R12 表明实际收益和学习者水平、练习量有关。

因此，Readict 的任务计数应区分“今天完成多少个词”“回答多少题”“重复了几次”和“下次应复习哪些内容”；不能把完成一轮当作长期学会。

## 5. 方案对比：固定多阶段 vs 动态多阶段

| 维度 | 方案 A：固定多阶段 | 方案 B：动态多阶段（研究建议） |
| --- | --- | --- |
| 初次接触 | 每词强制经过若干统一题型 | 先判断是否需要介绍／纠错，再进入提取 |
| 答对 | 仍按顺序完成剩余阶段 | 可以减少当轮额外题，保留跨日回访 |
| 答错 | 固定重新从某关起 | 明确反馈，稍后重试，失败多时控制上限 |
| 语境 | 每关同样或预置原句 | 视目标选择原句提示／独立词义／语境区分 |
| 优点 | 规则容易理解，QA 简单，教学一致 | 有望减少熟词额外题，按实际错误补充练习 |
| 主要风险 | 较多无效重复，阅读用户的会话过长 | 状态与反馈更复杂，需要验证透明度、公平性 |
| 证据判断 | 没有证明固定关数最优 | 有研究支持适应记忆表现的动机，**本方案本身未被实证** |

**研究性推荐**：以方案 B 为主候选，方案 A 为对照基线，先用低保真任务流程／可用性试验比较，**不直接进入开发排期**。

## 6. Readict 候选流程（不是不背单词的真实算法）

以下是未来 P1 复习模块的行为草案。它既保留多阶段结构，也允许提前结束或追加纠错。

```text
用户阅读时主动收藏 lemma 与原句（仍属于现有 V1.1）
       ↓ [用户之后主动进入独立复习]
选择待学／待复习条目
       ↓
【首次介绍】只针对尚未建立稳定词义联系的目标
显示词形、可信释义、用户原句、来源 → 继续
       ↓
【主动提取】隐藏目标含义，先尝试回忆
       ├─ 正确且较确定：记录通过 → 进入之后的间隔复习
       ├─ 模糊：展示正确含义与使用场景 → 研究是否需要稍后再测
       └─ 不会／答错：明确纠正 → 本轮后段给一次再次提取机会
                          ↓
           [若持续失败] 暂存为需加强，不无限卡住同一轮
       ↓
【复习结束】区分本轮完成、待补强、未来到期
       ↓
【跨日间隔复习】必要时改用不同原句或语境区分题
```

**可供实验的初始参数假设（非研究定论）**：每轮选 8～10 个收藏词；失败词同轮最多追加 1～2 次；允许“提前结束并保留未完成项”；给出可理解的结算。需通过真实时间成本和延迟测试优化。

### 6.1 逐词例子

以 `reluctant` 为例：

- 初次学习：词形 reluctant + 来源句 “She was reluctant to reveal the truth.” + 当前词义“不情愿的”。
- 第一次提取：只显示 reluctant / 音标（语境提示可选），用户先回忆后揭示。
- 回忆准确：本轮通过，后续日子再问，不要求固定完成拼写。
- 回忆失败：揭示词义并指出原句用法；经过其他单词后再次检查。
- 之后的另一轮：可展示陌生句子 “He seemed reluctant to accept the offer.” 检查能否在新情境理解（必须独立设计有效的参考答案）。

再看 `charge`：由于“收费／指控／充电”同形多义，独立无语境的“charge 是什么意思”**不能作为这三种义项的严格判分依据**，需要限定语境或学习目标；同词多义不能由词典常用第一个释义直接替代。

### 6.2 概念数据关系（非建表设计）

```text
收藏主体（user + lemma）
    └─ 多个原句与来源快照
    └─ （未来）不同词义／语境学习目标
           └─ （未来）独立或共享的复习状态与作答记录
```

**尚待决策**：究竟用 lemma 级一个长期状态、按义项分状态，还是按语境分状态。尽管用户希望“不同语境分别练习”，仍不能推出“每条原句都建独立 SRS 卡片”。按句独立调度可能产生卡片爆炸；按义项组织需要可信消歧，尤其当前 V1.1 的词性优先策略不等于精确词义判定。

## 7. 负担控制与算法研究

Anki 官方说明强调：FSRS 的 desired retention 越高，复习工作量通常越大；也建议不要依赖大量单日短间隔反复作为长期保持的替代。此处反映的是**通用权衡**，不意味着 Readict 必须采用 Anki 默认 90% 或 FSRS。

后续应比较：
1. 无限制重复 vs 每轮设失败重复上限。
2. 固定三关 vs 依据用户成功／失败动态变化。
3. 按词汇数结算 vs 按题次数结算。
4. 一天不复习／连续七天不复习的积压处理。
5. 词义级／语境级任务增多导致的队列膨胀。

算法阶段单独比较固定间隔、SM-2、FSRS，输入相同的用户反馈序列，展示日负担、遗忘情况及重试逻辑。**模拟数据不能用来声称真实记忆收益**。

## 8. 真实验证方案：两类试验不能混为一谈

### 8.1 用户任务可用性试验

探索阶段可先邀请约 5～8 名符合目标的英文原版书读者（不是统计效能样本），使用两套流程完成相同任务：
- 固定多阶段 vs 动态多阶段。
- 观察理解难度、任务完成时间、误触／纠错、重复焦虑、退出与再次进入。
- 询问为什么某张卡被判通过或继续复习，确认状态是否可理解。

### 8.2 初步记忆效果试验

建议先进行**可行性试验**，而非直接对外声称有效性：

- 让参与者预先测量对词的熟悉程度，平衡难度和词义数。
- 将每人 24～40 个目标词随机分配到两套流程，尽量平衡词组、单义、多义及先前熟悉度；具体样本数依据招募能力调整。
- 两条件控制总学习时间或预先定义固定时间预算，记录实际题数与错误次数。
- 学习后即时、7 天、14 天测试；**至少一部分题使用未在练习中见过的新英文语境**，不只重复原句。
- 主要指标：陌生语境下目标义项识别正确率；次要指标：无提示词义回忆、单位时间收益、退出率与主观负担。
- 必须预先规定主要结局和统计方案；小规模样本主要看可行性与效应方向，不推断普遍优劣。

特别注意：卡片所用的释义必须先由可信词典／人工校验，避免词义质量成为混杂因素。

## 9. 决策建议与尚未验证的问题

### 9.1 建议“优先探索”，不是“批准开发”

1. 保留独立复习入口与用户主动收藏的边界。
2. 借鉴不背单词 **先提取 → 揭示 → 分级反馈／纠错 → 条件性重复 → 本轮结算** 的交互骨架。
3. 新学引导与后续复习做内容和提示强度区分，不强迫所有词统一关卡数量。
4. 将个人原句视为关键资产，但根据任务区分“解释辅助”和“答案提示”。
5. 不强制拼写，不把中译英设为核心通过条件。
6. 本轮完成、长期到期与语境知识要在后续业务规则中分别定义。

### 9.2 需要继续研究／验证的阻塞点

| 问题 | 重要性 | 下一步证据 |
| --- | --- | --- |
| 不背单词纯净首次学习、收藏词到主复习队列 | 高 | 干净样本针对性实测 |
| 一个 lemma 多义时如何定义复习目标 | 很高 | 真实多义语料、词义归类准确率、方案对比 |
| 多阶段中各题型真正测量的能力 | 高 | 对照设计、延迟与迁移测试 |
| 自评“模糊”的含义及与记忆状态映射 | 高 | 用户对评分的理解、历史反馈分析 |
| 同轮错误追加几次才合适 | 中高 | 训练负担与延迟记忆对照 |
| 长期调度使用哪个算法 | 中 | 同输入离线比较；后续真实历史校准 |
