> 研究时间：2026-11-23。状态：**研究报告已形成，待产品评审**。**不代表批准后续复习 PRD／算法或开发范围**。

## 当前结论（仅研究建议）

- **不背单词作为复习交互主参考**：题前主动提取、题后揭示、认识／模糊／忘记、自评纠错、按表现补充练习、分层结算。
- **Readlang 作为语境组织主参考**：用户原文、多语境与来源关联；但不照搬点译即积累。
- **首选研究候选**：动态多阶段接受性词义学习；与固定多阶段方案对照，要求真实用户验证。
- **暂不批准**：固定关卡数、重试次数、用户完成标准、词义级调度、FSRS 等具体实施细节。

## 研究质量限制

资料来自既有竞品操作、公开论文和算法文档；并未完成真实 Readict 用户的长期记忆试验。跨日调度与不背单词内部公式不可从阶段一短会话还原。

Readict V1.1 的既定边界不变：仅主动收藏、同 lemma 一收藏主体、关联多个原句，复习功能不进入当前 P0。
